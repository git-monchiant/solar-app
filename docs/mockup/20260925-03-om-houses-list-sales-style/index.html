ยกโครงหน้าของ Pipeline / งานบริการมาใช้ (หัวหน้า ListPageHeader + แถวเครื่องมือ) แต่เนื้อหาบน desktop ยังเป็นตาราง เพราะหน้านี้คือทะเบียนบ้านสำหรับไล่ตรวจ/เติมข้อมูล ไม่ใช่งานที่เดินเป็นขั้น — มือถือเป็นการ์ดเหมือนเดิม ท้ายหน้ามี 3 เรื่องให้เลือก (กรอบเขียว = แนะนำ)

4 · เรื่องให้ตัดสินใจ

เลือกเรื่องละ 1 ทาง — กรอบเขียวคือทางที่แนะนำ (ภาพ desktop ด้านบนใช้ A1 + B1 + C1)

A กล่อง sync 3 ใบบนสุด

ทั้ง 3 ใบเป็นเครื่องมือแอดมิน แต่กินพื้นที่ ~250px บนหน้าที่ทุกคนใช้ · API สถานะ sync อ่านได้เฉพาะ admin / solar_sup / sales_sup — role อื่นเห็นกล่องนี้เป็น "0 unit · รอบล่าสุด —" มาตลอด ⇒ ไม่ว่าเลือกทางไหน ควรแสดงเฉพาะ 3 role นี้ · ตอนนี้ทะเบียน REM ขึ้น "ล่าสุด 9 ก.ย." คือไม่ได้ดึงมา 16 วัน ทั้งที่ควรดึงทุก 6 ชม. ถ้าย่อต้องยังเห็นเรื่องแบบนี้

A1 ย่อเหลือบรรทัดเดียวในแถวเครื่องมือ · แนะนำ

⟳ ดึงทะเบียนเดี๋ยวนี้
✓หน้าสั้นลง ~220px แต่สถานะยังอยู่ตรงที่ข้อมูลแสดง — ตัวเลขดูแปลกเมื่อไรก็เห็นสาเหตุทันที
✓จุดส้ม = ข้อมูลเก่ากว่าที่ควร (REM > 1 วัน · กวาดงานขาย > 2 ชม.) · ป้าย "รอคนตัดสิน" โผล่เฉพาะตอนมีของค้าง
✕รายละเอียด (แถบความคืบหน้า / จำนวนเจ้าของ) ต้องกดดู
A2 ย้ายทั้งกล่องไปหน้า "ตั้งค่า O&M"
หน้าบ้านเหลือแค่ป้าย รอคนตัดสิน 1 → เมื่อมีของค้าง
กล่อง 3 ใบไปอยู่ /om/settings (เห็นเฉพาะ admin / solar_sup / sales_sup)
✓หน้าบ้านสะอาดที่สุด · ทีมหน้างานไม่เห็นของที่ไม่ใช่งานตัวเอง
✕REM หยุดดึงแบบตอนนี้จะไม่มีใครเห็น จนกว่าแอดมินจะเข้าหน้าตั้งค่า
A3 คงไว้แบบเดิม
กล่อง 3 ใบ ~250px อยู่บนสุดเหมือนเดิม
✕หน้าไม่เหมือนฝั่งขาย · ตารางเริ่มต่ำลงเกือบครึ่งจอ

B แท็บ "ถึงคิวล้าง"

เรื่องเดียวกันแต่ตัวเลขไม่ตรงกันสองหน้า — นิยามต่างกัน: หน้านี้นับทุกหลังที่ไม่เคยล้างหรือเลยรอบ · หน้างานบริการแยกหลังที่ไม่มีเบอร์ / โทรไม่ติด / สิทธิ์หมด ออกไปแท็บอื่น

1,546บ้าน / ระบบติดตั้ง · แท็บ "ถึงคิวล้าง"
919งานบริการ · แท็บ "ติดตาม" (ที่เหลือไปอยู่ ติดต่อไม่ได้ 277 · สิทธิ์หมด 463 ฯลฯ)
B1 เอาแท็บออก — คิวล้างดูที่งานบริการที่เดียว · แนะนำ
ถึงคิวล้าง (1,546)
ในตารางยังเห็นคอลัมน์ "ล้างล่าสุด" (สีส้มเมื่อเลยรอบ) เหมือนเดิม
✓คนใช้เห็นตัวเลขคิวล้างชุดเดียว · หน้านี้เหลือแท็บเรื่องคุณภาพข้อมูลล้วน ๆ
✕อยากได้รายชื่อบ้านที่ไม่เคยล้างทั้งหมด (รวมหลังที่ไม่มีเบอร์/สิทธิ์หมด) ต้องไปรวมจากหลายแท็บในหน้างานบริการ
B2 คงไว้ เปลี่ยนชื่อเป็น "ไม่เคยล้าง / เลยรอบ"
แท็บ ไม่เคยล้าง / เลยรอบ (1,546) + หมายเหตุใต้แท็บ "ไม่ใช่คิวโทร — คิวโทรอยู่หน้างานบริการ"
✓ยังกรองบ้านที่ไม่เคยล้างได้จากหน้าทะเบียน
✕ยังมีสองตัวเลข ต้องอ่านหมายเหตุถึงจะเข้าใจ

C ปุ่ม "+ เพิ่มบ้าน"

ตอนนี้ปุ่มไม่ได้ผูกคำสั่งอะไรไว้ — กดแล้วไม่มีอะไรเกิดขึ้น · บ้านเข้าระบบเองอยู่แล้ว 3 ทาง: ทะเบียน REM (ทุก 6 ชม.) · งานขายที่ติดตั้งเสร็จ (ทุก 1 ชม.) · คิวจับคู่ที่แอดมินตัดสิน

C1 เอาปุ่มออกไปก่อน · แนะนำ ถ้ายังไม่มีเคสจริง
ช่องค้นหาเต็มความกว้าง ไม่มีปุ่มข้าง ๆ (แบบในภาพ desktop)
✓ไม่มีปุ่มหลอก · ไม่มีบ้านที่สร้างมือแล้วชนกับบ้านที่ REM ส่งมาทีหลัง
✕ถ้ามีลูกค้าที่ไม่อยู่ใน 3 ทางนี้ ต้องให้แอดมินเพิ่มผ่านข้อมูลนำเข้า
C2 ทำฟอร์มเพิ่มบ้านจริง
+ เพิ่มบ้าน → เปิด modal แบบเดียวกับรายละเอียดบ้าน (ช่องว่าง): บ้านเลขที่ · โครงการ (ไม่บังคับ) · ลูกค้า · เบอร์ · ขนาดระบบ · วันติดตั้ง
✓รองรับลูกค้านอกระบบ เช่น ติดตั้งกับเจ้าอื่นแล้วมาใช้บริการ O&M
✕งานเพิ่ม: API สร้างบ้าน + กันบ้านซ้ำกับ REM · ต้องตกลงว่าใครกดได้
