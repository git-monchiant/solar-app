5จุดที่ต้องกันไว้ตอนลงมือ

admin ที่กดการ์ด O&M ไว้ล่าสุด — เครื่องยังจำโมดูล om_package ไว้ พอเลิกใช้ key นี้ เมนูซ้ายจะตกไปโมดูลแรก (Seeker) ทั้งที่อยู่หน้าจัดการแพ็กเกจ O&M → ให้ getModule() แปลง om_package เป็น package (บรรทัดเดียว)
ไอคอนตอนย่อเมนู — ลูกในกลุ่มแสดงเป็นไอคอนเรียงกัน ไอคอน 4 อันต้องไม่ซ้ำกัน (☀ / กล่อง · ประแจ / คลิปบอร์ด)

6ให้เคาะ

D1 · เมนูซ้าย
  1. ก)แยก 2 กลุ่มพับได้ Solar Rooftop / O&M (แนะนำ)
  2. ข)เมนูเรียบ 4 บรรทัด
D2 · ชื่อและคำอธิบายการ์ด
  1. ก)“Package” · “แพ็กเกจ Solar · O&M · แคตตาล็อก · จัดการ” (แนะนำ — ชื่อภาษาอังกฤษแบบการ์ดอื่น)
  2. ข)“แพ็กเกจ” · คำอธิบายเดียวกัน
D3 · ป้ายตอนชี้ไอคอนในเมนูที่ย่อ (เฉพาะแบบ A)
  1. ก)ใส่ชื่อกลุ่มนำหน้า เช่น “O&M · แคตตาล็อก” (แนะนำ) — ใช้กับทุกโมดูลที่มีกลุ่ม เช่น Sales จะขึ้น “ติดตั้ง · รอติดตั้ง” แก้ BottomNav จุดเดียว
  2. ข)ไม่แก้ ใช้ไอคอนต่างกันพอ
D4 · กดการ์ดแล้วลงหน้า
  1. ก)แคตตาล็อก Solar (แนะนำ — เหมือนการ์ด Package ตอนนี้)
  2. ข)จัดการแพ็กเกจ Solar (การ์ดนี้ admin ใช้แก้ราคาเป็นหลัก)
