ทุกแบบใช้ข้อมูลชุดเดียวกัน — ป้าย ถึงตาเรา รออนุมัติ รอลูกค้า รอบัญชี สีตาม "คนที่ต้องทำ" · ตัวเลขวัน = อยู่ในขั้นนี้มากี่วัน (เกิน 7 วันเป็นสีแดง)

อ่านยังไง

  • แถบบน = เส้นทางขาย 5 ขั้น · ตัวเลขใหญ่ = จำนวนโครงการ · ใต้ตัวเลข = มูลค่ารวม + ถึงตาเรากี่งาน · กดขั้นไหน = กรองตารางเหลือขั้นนั้น (ลองกดได้)
  • แต่ละแถว: รางขั้น ●●●○○ (จุดม่วง = ขั้นปัจจุบัน) · ต่อไป = งานที่ต้องทำ · ป้าย = รอใคร

ต่างจากเดิม

  • ชิปกรอง "ถึงตาเรา / รออนุมัติ / รอลูกค้า / รอบัญชี" — เปิดมาเห็นทันทีว่างานไหนต้องทำเอง
  • BOQ หลายขนาดแสดงช่วง "150 – 200 kWp · 2 ขนาด" แทน "— · 2 ตัวเลือก" · คอลัมน์ "อยู่ขั้นนี้" แทน "อัปเดตล่าสุด"
