## ขั้นตอนใหม่

งานแยก 2 เส้นตั้งแต่ขั้นติดตาม

- **เส้น A (ฟรี)** — ข้ามขั้น 2–3 ไปนัดได้เลย
  - ล้างตามรอบและยังมีสิทธิ์เหลือ (ปิดงานแล้วตัดสิทธิ์ 1 ครั้ง)
  - ซ่อมในประกันการติดตั้ง (ข้อ 7 — ไม่ตัดสิทธิ์ล้าง) · ทีม O&M ติ๊ก "ในประกัน" ตอนเปิดใบงานซ่อม
    ระบบโชว์วันติดตั้ง/วันเริ่มประกันจาก `om_installations` ให้ดูประกอบ ยังไม่คำนวณหมดประกันอัตโนมัติ
- **เส้น B (เสียเงิน)** — สิทธิ์หมด / ซ่อมนอกประกัน / งานเพิ่ม → ต้องผ่านเสนอราคา อนุมัติ รับเงิน ก่อนนัด
  (หมายเหตุใน Package O&M: "เก็บค่าบริการก่อนนัดหมาย")

| # | ขั้น | ขั้นย่อย | ใครทำ |
|---|---|---|---|
| 1 | **ติดตาม** | ถึงรอบล้าง / ลูกค้าแจ้งเข้ามา · โทรหาลูกค้า | Sale / ทีม O&M |
| 2 | **เสนอราคา** *(เส้น B)* | 2.1 ร่างใบ — เลือกจาก Package O&M ตามขนาด kW (รายครั้ง / สัญญา 12 เดือน) หรือรายการซ่อม | Sale |
| | | 2.2 รอ Solar Sup อนุมัติ — ตรวจขนาดระบบ จำนวนแผง ขอบเขตงานซ่อม | Solar Sup |
| | | 2.3 รอ Sale Sup อนุมัติ — ตรวจราคา ส่วนลด | Sale Sup |
| | | 2.4 ส่งกลับแก้ → กลับ 2.1 แล้วเริ่มที่ Solar Sup ใหม่ | — |
| | | 2.5 อนุมัติแล้ว → ส่งให้ลูกค้า | Sale |
| 3 | **ชำระเงิน** *(เส้น B)* | 3.1 รอลูกค้าชำระ · แนบสลิป | Sale |

| | | 3.3 รับเงินแล้ว → ถ้าเป็นสัญญา ระบบเติมสิทธิ์ 2 ครั้งให้บ้านนั้น | ระบบ |
| 4 | **นัดหมาย** | 4.1 รอยืนยันนัด → 4.2 นัดแล้ว (มอบทีมช่าง) | ทีม O&M |
| 5 | **เข้างาน** | กำลังล้าง / ตรวจระบบ · กรอกใบตรวจรับงาน | ช่าง |
| 6 | **รอปิด** | ลูกค้ายืนยัน / ตรวจรับ | ทีม O&M |
| 7 | **ปิดงาน** | เส้น A ตัดสิทธิ์ 1 ครั้ง · เริ่มนับรอบถัดไป | ระบบ |

**ทางออก** (เกิดได้ระหว่างทาง): ไม่เอา (ปฏิเสธราคา) · ติดต่อไม่ได้ · ยกเลิก · ลูกค้าไม่อยู่บ้าน

**งานซ่อมที่เจอหน้างาน** (คำตอบข้อ 2): ช่างบันทึกในใบตรวจรับงานขั้น 5 → ระบบเปิด**ใบงานใหม่ประเภทซ่อม**
ที่ขั้น 2 (ผูกกับใบงานเดิม) · ใบงานล้างเดิมปิดตามปกติ ไม่ค้างรอเรื่องซ่อม — 1 ใบงาน = 1 เส้นทาง

ชื่อขั้นชุดนี้ใช้แทนชื่อเดิม ("ทำนัด" / "รอ O&M" / "เข้า O&M") ทุกหน้าจอ
= แก้ปัญหาชื่อสถานะ 3 ชุดไม่ตรงกัน และแถบ 5 ขั้นขาด "รอปิด" ที่ทบทวนไว้ 24 ก.ย. ไปพร้อมกัน
