# รายงานสำรวจ §3: เน้นตัวเลขที่ใช้ประเมิน Battery

วันที่: 12 ต.ค. 2569 · branch: `v3-ui-consistency` (ทำในเครื่อง)
ต่อจาก: [20261012-02-load-note-plain-wording.md](20261012-02-load-note-plain-wording.md)

## ที่มา

ผู้ใช้: §3 มีไว้ประเมินว่าควรติด Battery ไหม ตัวเลขที่จำเป็นควรเน้นหรือมีสีพื้นให้ดูง่าย
ตาราง "สรุปการคำนวณ" เดิมมี 5 แถวหน้าตาเท่ากัน ตัวตัดสิน (สัดส่วนกลางคืน) จมอยู่แถวที่ 2

เสนอ 5 ทาง ผู้ใช้สั่ง "ทำตามแนะนำ" = ข้อ 1 + 2 + 4 + คำกำกับเมื่อข้อมูลครอบคลุมบิลน้อย

## การตัดสินใจ

- **D1** แยกตารางสรุปเป็น 2 กลุ่ม (หัวซ้าย rowspan):
  - **ใช้ประเมิน Battery** (หัวสีกรม) — แถวแรก "สัดส่วนใช้ไฟกลางคืน" พื้นฟ้าอ่อน ตัวเลข % ใหญ่ 17px
    + แถวที่สอง "ใช้ไฟรวมต่อวัน"
  - **ตรวจกับบิลค่าไฟ** (หัวสีเทา) — ต่อเดือน / ไฟตามบิล / เทียบกับบิล ตัวเล็ก 12px สีเทา (แสดงเมื่อตอบครบเหมือนเดิม)
- **D2** แถบสัดส่วนในแถวแรก: กลางคืนสีกรมจากซ้าย กลางวันสีส้ม (สีเดียวกับช่องรวมในตาราง)
  + กรอบช่วง 40–50% ป้าย "เกณฑ์ทั่วไป 40–50%" (คำเดียวกับกล่อง Battery "ทั่วไป > 40-50%")
- **D3** ไม่ฟันธง — แสดงตัวเลขกับเกณฑ์เท่านั้น ไม่มีป้าย "ควรติด Battery" (คงมติ D3 ของ
  [20260928-01](20260928-01-load-assumption-questionnaire.md): เซลส์อาจเสนอ On-Grid ไปแล้ว รายงานจะขัดกับใบเสนอราคา)
- **D4** ตารางอธิบายบิลได้ < 70% → ใต้แถบขึ้นสีส้ม "ตารางนี้อธิบายการใช้ไฟได้เพียง ≈ X% ของบิล สัดส่วนจริงอาจต่างจากนี้"
