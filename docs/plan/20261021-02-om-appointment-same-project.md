## หน้าตา (ดู mockup)

ทั้งหมดอยู่ในส่วน "นัดเข้าบริการ" ของขั้น 04 และ Reschedule ขั้น 05 (ใช้ `OmSlotPicker` ตัวเดียวกัน)

**① แถบแนะนำวัน** — เหนือปฏิทิน: `📍 ทีมเข้า <ชื่อโครงการ> อยู่แล้ว` + ชิปวัน
- ชิป: `พฤ 22 ต.ค. · 118/32 09:30 · ว่าง 15 ช่อง` (หลายหลัง = `2 หลัง`) · กด = เลือกวันนั้น (เหมือนกดในปฏิทิน)
- วันที่เลือกได้เท่านั้น (ไม่ผ่านแล้ว · ไม่เกิน `booking.advance_days_max`) · เรียงใกล้สุด · ไม่เกิน 5 ชิป
- ไม่มีนัดในโครงการ / บ้านไม่มีรหัสโครงการ = **ไม่แสดงแถบ** (ผู้ใช้ไม่ชอบกล่องคำอธิบายในขั้น 04 — 1 ต.ค. 69)
- มือถือ: ชิปเลื่อนแนวนอนแถวเดียว

**② วันบนปฏิทิน** — วันที่มีนัดโครงการเดียวกัน = วงกรอบเขียว (`ring-2 ring-emerald-500`) จุดสีทีมยังอยู่
- tooltip: `เสนา วิลเลจ บางปะกง 1 นัด · ที่อื่น 2 นัด (นัดทับได้)`
- ใช้รูปทรง (วงกรอบ) แยกจากจุด teal ของ O&M — ไม่พึ่งสีอย่างเดียว

**③ ช่วงเวลา** — หัวข้อเพิ่ม `ว่าง x / 16 ช่อง` ชิดขวา

| สถานะช่อง | หน้าตา | กดได้ |
|---|---|---|
| ว่าง | ขาว (เดิม) | ได้ |
| ต่อคิวได้ — ว่าง + ติดก่อน/หลังช่องที่มีนัดโครงการเดียวกัน | กรอบเขียวประ + คำ "ต่อคิว" | ได้ |
| มีนัดโครงการเดียวกัน | พื้นเขียวอ่อน + บ้านเลขที่ (เช่น 118/32) | ได้ (นัดทับได้) |
| มีนัดที่อื่น | จุดสีทีม (เดิม) | ได้ |
| ปิดช่อง / เลยเวลา | เทา (เดิม) | ไม่ได้ |

- "ว่าง" = ไม่มีนัด O&M / สำรวจ (ทุกโครงการ — ทีมมีชุดเดียว) · ไม่ปิด · ไม่เลยเวลา — **ติดตั้งไม่หักช่องว่าง** (คนละทีม)
- มือถือ (ช่องแคบ 4 คอลัมน์): ไม่แสดงคำ แสดงเป็นจุด/กรอบสีเขียวแทน

**④ รายการนัดของวันที่เลือก** — แทนบรรทัด "วันที่เลือกมีนัด • O&M 1 — จุดคือช่องที่ติดนัด · ยังนัดทับได้"
- แถวละนัด: เวลา (ช่วง) · จุดสี + ประเภท · บ้านเลขที่ ชื่อ · ชื่อโครงการ · ป้าย `โครงการเดียวกัน` (เขียว)
- เรียงโครงการเดียวกันก่อน แล้วตามเวลา · ติดตั้ง = `ทั้งวัน` อยู่ท้าย

## งานที่ต้องทำ (ไม่มี migration)

### 1. API `GET /api/surveys/scheduled` — เพิ่มโครงการ (แบบเติมคอลัมน์ ของเดิมไม่เปลี่ยน)
- query หลัก (ฝั่งขาย): เพิ่ม `project_id AS sales_project_id` ในแถวสำรวจ/ติดตั้ง (คอลัมน์มีทั้ง v2/v3)
- query O&M (ใน `IF OBJECT_ID`): เพิ่ม `h.project_id rem_project_id` + `pj.name_th project_name`
  และดึง `om_project_map` (rem_project_id ไม่ว่าง) + ชื่อจาก `om_projects` มาเติม `rem_project_id`/`project_name` ให้แถวสำรวจ/ติดตั้งใน JS
- DB ที่ไม่มีตาราง O&M (v2) = ไม่มีคอลัมน์ใหม่ — หน้าจอต้องรับค่าว่างได้
- ผู้ใช้ปลายทางอื่น (`EventCalendarMonth` / `EventCalendarList` / `NewAppointmentModal` / SurveyStep / PreSurveyStep) ไม่กระทบ — เพิ่มฟิลด์อย่างเดียว

### 2. `CalendarPicker` — prop ใหม่ `sameProject?: { id: string; name: string } | null`
- ไม่ส่ง = หน้าตาเดิมทุกจุด (ฝั่งขายไม่เปลี่ยน)
- ส่งมา (ใช้คู่กับ `overlap="warn"`): ① แถบชิป ② วงกรอบวัน ③ สถานะช่อง + ตัวนับว่าง ④ รายการนัด
- นับ "เข้าโครงการ" เฉพาะ `event_type` `om` / `survey` ที่ `rem_project_id === sameProject.id`
- คำนวณช่องว่างจากชุดเดียวกับจุด (`infoByDate`) + `bookedSlotsByDate` (ปิดช่อง) + `slotDisabled` (เลยเวลา)
- ชิปใช้ `maxDate` + วันนี้เป็นขอบ · กดชิป = เส้นทางเดียวกับคลิกวัน (ตัดช่องที่ถูกปิดออก)

### 3. `OmSlotPicker` / `OmRescheduler` / `JobDetail`
- `OmSlotPicker` รับ `project?: { id, name }` ส่งต่อเป็น `sameProject`
- `JobDetail` ส่ง `item.project_id` + `item.project_name` (เพิ่มใน type ถ้ายังไม่มี) ทั้งขั้น 04 และ `OmRescheduler` ขั้น 05
- ใบงานตัวเองไม่นับ (`excludeOmBookingId` เดิม)
