ผู้ใช้ถามว่า "ที่เมนู Pipeline ต้องปรับให้เหมือนกับ Today ไหม" ตอนไปตรวจเจอสองเรื่อง
เรื่องแรกเป็นบั๊กที่ทำให้เซลส์อ่านข้อมูลผิดทุกวัน เรื่องที่สองคือของที่ค้างครึ่งทาง

## 1. Pipeline ติดป้าย "เลยนัดแล้ว" ผิด

Lead 1038 ปรีชา (กรีนวัลเล่) นัดวันที่ 26 ส.ค. ซึ่งคือวันนี้ ตรวจพร้อมกันสองหน้าเมื่อ 16:14 น.

| หน้า | ข้อความ | สี |
| --- | --- | --- |
| Today | `นัดลูกค้า 26 ส.ค.` | เทา |
| Pipeline | `นัดลูกค้า 26 ส.ค. · เลยนัดแล้ว` | ส้ม |

`/api/leads` ไม่เคยส่ง `is_followup_overdue` มา `LeadCard` จึงตกไปใช้สูตรสำรองฝั่ง
browser ที่เทียบกับ **เที่ยงวัน** ผลคือหลังเที่ยงของทุกวัน นัดของวันนั้นกลายเป็น
"เลยนัด" ทันที และสูตรสำรองยังไม่ได้เช็คอีกสองข้อที่ฝั่ง SQL เช็คไว้

| ข้อ | กติกาฝั่ง SQL (Today) | สูตรสำรอง (Pipeline เดิม) |
| --- | --- | --- |
| 1 | ต้องเลย **วัน** ที่นัดจริง ๆ | เทียบกับเที่ยงวัน |
| 2 | ไม่นับ status `install` / `lost` | ไม่เช็ค |
| 3 | ถ้าตามไปแล้วตั้งแต่วันนัด ไม่ถือว่าค้าง | ไม่เช็ค |

ผลกระทบวันที่ตรวจ: Lead ที่นัดวันนี้ **28 ราย** และ Lead ที่ยกเลิกไปแล้วอีก **110 ราย**

### ที่แก้

- ย้ายนิพจน์ไป `src/lib/lead-followup-sql.ts` เป็นที่เดียวของทั้งระบบ
  พร้อม `LAST_FOLLOW_UP_APPLY` ให้ query ที่ไม่มี `act` join แบบ `/api/today` ใช้ได้
- `/api/today` เรียกผ่าน helper — ก้อน SQL เดิม ผลลัพธ์เดิม
- `/api/leads` เพิ่มคอลัมน์ `is_followup_overdue` ทุกหน้าที่ใช้ `LeadCard` ได้ตามไปด้วย

### ผลตรวจจริง

| ตรวจ | ผล |
| --- | --- |
| `/api/today` เทียบ baseline ก่อนแก้ | Lead 316 ราย ค่าเปลี่ยน 0 ราย |
| `/api/leads` ส่ง flag แล้ว | 547/547 ราย |
| Lead ที่นัดวันนี้ยังโดนตีว่าเลยนัด | 0 (เดิม 28) |
| Lead status `install`/`lost` ยังโดนตี | 0 (เดิม 110) |
| สอง API ขัดกันบน Lead ที่มีร่วมกัน | 0 จาก 316 |
| หน้าจริง Lead 1038 | ทั้งสองหน้าขึ้น `นัดลูกค้า 26 ส.ค.` สีเทาเท่ากัน |
| `/api/leads` median 5 ครั้ง | 436 ms ไม่ช้าลงจากเดิม |

## 2. ยกชิปตัวกรอง SLA ไป Pipeline

Pipeline โชว์กล่อง SLA บนการ์ดทุกใบอยู่แล้ว (`/api/leads` ส่ง `sla_status`, `sla_due_at` มาครบ)
แต่กรองไม่ได้เลย ทั้งที่มี 547 รายการ

- แยกนิยามที่ใช้ร่วมกันไป `src/lib/sla-filter.ts` (สี, ลำดับ, กติกา exclusive, parse, toggle)
- แยกแถวชิปไป `src/components/sla/SlaFilterChips.tsx` — Today ส่ง popover "ตัวกรองย่อย"
  เข้ามาทาง `trailing` markup จึงเหมือนเดิมทุกตัวอักษร
- Pipeline นับเองแบบง่ายกว่า Today เพราะเป็น list แบน — นับตัว Lead ตรง ๆ
  ไม่ต้องรวมจากหลาย bucket

### สองจุดที่ตั้งใจให้ต่างจาก Today

| เรื่อง | Today | Pipeline | เหตุผล |
| --- | --- | --- | --- |
| ที่จำค่า | URL (`?sla=`) | `localStorage` (`pipeline.sla`) | Pipeline เปิดค้างทั้งวัน Today ใช้ส่งลิงก์หากัน |
| ตำแหน่งแถว | ใต้แท็บ | ใต้แท็บ (ในตัวหน้า) | ไม่ใส่ `tabsRight` เพราะซ่อนบนจอแคบ จะติ๊กแล้วปลดไม่ได้ และแท็บ 13 ปุ่มไม่มีที่ว่าง |

ไม่ยกมา: ปุ่ม "ตัวกรองย่อย" (แท็บสถานะของ Pipeline ทำหน้าที่นั้นอยู่แล้ว)
และการสลับไปเรียงตามความเร่งด่วน SLA (ไม่แตะการเรียงของ Pipeline)
