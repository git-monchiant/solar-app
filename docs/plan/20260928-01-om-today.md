# Today ของ O&M — อยู่ในการ์ด O&M เท่านั้น

ผู้ใช้สั่ง 28 ก.ย. 69: "อยากให้ Today งาน O&M แสดงเฉพาะในการ์ด O&M ไปก่อน"
สถานะ: **เสร็จ 28 ก.ย. 69**

## ที่มา

- หน้า `/today` เป็นหน้าเดียว เปิดได้จากเมนูซ้ายของการ์ด **Sales** กับ **สำรวจ & ติดตั้ง** — การ์ด O&M ไม่มีเมนู Today
- แผน 20260922-01 ข้อ 4.1 (ผู้ใช้เคาะ 24 ก.ย.): งาน O&M อยู่ในการ์ดตัวเองก่อน ห้ามไปปน Today ที่ทีมขายเปิดทุกวัน
- ⇒ ทำ **`/om/today`** ของ O&M เอง แบบเดียวกับที่ทำ `/om/dashboard` แทนแท็บใน `/dashboard` ฝั่งขาย
  **ไม่แตะ `today/page.tsx` เลย**

## ผู้ใช้เคาะ (28 ก.ย. 69)

- เมนู "Today" บนสุดของการ์ด O&M (ตำแหน่งเดียวกับ Sales / สำรวจ & ติดตั้ง) · ไม่มี badge เหมือน Today ฝั่งขาย
- ติ๊ก **"งานของฉัน"** เหมือน Today ฝั่งขายทุกอย่าง: ขวาของแถวเครื่องมือ · ค่าเริ่มต้นไม่ติ๊ก (เห็นงานทุกคน)
  · ติ๊กแล้วเหลือใบงานที่ตัวเองเป็นเจ้าของ ตัวเลขแท็บขยับตาม · จำค่าในเบราว์เซอร์
  (ของเดิม: `today/page.tsx` ติ๊กเดียวกัน ค่าเริ่มต้นไม่ติ๊ก API ส่งทุก lead มา)

## แท็บ (ตอบ "วันนี้ต้องทำอะไร") — 1 บ้านอยู่แท็บเดียว

## ของที่ยกมาใช้ (กติกา ui-rules)

- โครงหน้า = `/om/services` (ListPageHeader + แถวเครื่องมือ + JobCard + ติ๊กงานของฉัน) ซึ่งยกจาก Pipeline/Today อยู่แล้ว
- หัวเรื่อง = ชื่อเมนู ("Today") · subtitle = วันที่แบบหน้า Today ฝั่งขาย
- ข้อมูล = `OM_FOLLOW_SCOPE_SQL` ก้อนเดียวกับหน้างานบริการ/ภาพรวม (กติกาใน follow-sql.ts: ใครนับงานบริการให้ต่อท้ายสคริปต์นี้)
- การ์ด = `JobCard` · กดแล้วเปิดหน้ารายละเอียดบ้านเดิม (`useOpenOmService`)

## ตรวจ

- ตัวเลขบนแท็บ = จำนวนที่เปิดเห็น (ทั้งติ๊กและไม่ติ๊กงานของฉัน)
- จำลองข้อมูลให้ครบ 4 แท็บ · ล้างข้อมูลทดสอบ · หน้า `/today` ฝั่งขายไม่เปลี่ยน
- tsc / eslint · หน้า 200 · screenshot ไม่มี error

## ผล (เสร็จ 28 ก.ย. 69)

**ของที่ทำ**
- `GET /api/om/today?tab=&mine=&q=` — ต่อท้าย `OM_FOLLOW_SCOPE_SQL` + CASE แท็บ · ตัวเลขแท็บกรองงานของฉัน/คำค้นเหมือนรายการ
  (แบบ Today ฝั่งขาย) · ไม่แบ่งหน้า เพดาน 200 ใบ เกินแล้วหน้าบอก "แสดง N จาก M"
- `follow-sql` #job/#x เพิ่ม `scheduled_day` (วันนัดเวลาไทย) — คอลัมน์เพิ่มอย่างเดียว ตัวเลขหน้าอื่นไม่ขยับ
- `TODAY_TABS` ใน `service-view.ts` (ชื่อแท็บ · คำอธิบาย · ข้อความว่าง) ใช้ร่วม API กับหน้า
- หน้า `/om/today` + เมนู "Today" บนสุดของการ์ด O&M · จำติ๊กงานของฉันที่ `om.today.mineOnly` (แยกจาก `today.mineOnly` ฝั่งขาย)

**ตรวจ (15 ข้อผ่าน)** — จำลอง 6 บ้าน: นัดวันนี้ · นัดเลยมา 3 วัน · ไม่รับสายนัดโทรวันนี้ · ขอเลื่อนถึงเมื่อวาน · มีใบเสนอราคา · นัดโทรพรุ่งนี้
- ทุกแท็บตัวเลข = รายการ · บ้านอยู่แท็บถูก · นัดโทรพรุ่งนี้ยังไม่ขึ้น · 1 บ้านอยู่แท็บเดียว · ตัวเลขเพิ่มตรงกับที่จำลอง
- ติ๊กงานของฉัน (ผู้ใช้ 45 เจ้าของใบเดียว) เหลือ 1 และตัวเลขแท็บขยับตาม · ค้นบ้านเลขที่ ตัวเลข = รายการ
- `/api/today` ฝั่งขายเหมือนเดิมทุกไบต์ ขณะมีงาน O&M + lead O&M · ล้างข้อมูลแล้วตัวเลข Today เท่าเดิม
- เทียบตัวเลขเฟส 6 ซ้ำผ่านครบ · tsc/eslint ผ่าน · screenshot desktop/มือถือ ไม่มี error

**ข้อสังเกต** — แท็บ "โทรวันนี้" นับเฉพาะบ้านที่มีวันนัดโทรใหม่ (ตั้งจากผลโทร ไม่รับสาย/ขอเลื่อน)
บ้านที่ถึงรอบแต่ยังไม่เคยมีใครโทร (~900 หลังในแท็บติดตาม) ไม่ขึ้นที่นี่ — ยังโทรจากหน้างานบริการเหมือนเดิม
