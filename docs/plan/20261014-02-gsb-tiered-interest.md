# สินเชื่อออมสิน: คิดดอกเบี้ยขั้นบันไดตามประกาศ (ไม่มีหลักประกัน)

วันที่: 14 ต.ค. 2569 · branch: `v3-ui-consistency` · สถานะ: done
เกี่ยวข้อง: [20261012-06](20261012-06-quotation-payment-method-sections.md) (หมายเหตุถึง BTC เรื่อง Excel)

## ที่มา

- ระบบคิดสินเชื่อออมสิน 3.5% ทุกปี (`loan-defaults.ts` เขียนว่า "ไม่ใช่อัตราขั้นบันได") — ไม่ตรงประกาศปัจจุบัน
- Excel ของ BTC ใช้ 3.5 / 4 / 5 / 7 / 7 / 7 / 7 — ขั้นบันไดแต่ตัวเลขไม่ตรงประกาศ
- ประกาศทางการ [gsb.or.th/promotions/gsbsolar4life](https://www.gsb.or.th/promotions/gsbsolar4life/) (เปิดดู 14 ต.ค. 69)
  ลูกค้าทั่วไป · Clean Loan (ไม่มีหลักประกัน) · ดาวน์ 20% · กู้สูงสุด 7 ปี · วงเงินไม่เกิน 500,000:
  **ปีที่ 1–2 = 3.500% · ปีที่ 3–5 = 5.000% · ปีที่ 6 เป็นต้นไป = MRR 6.045% (มีผล 2 มี.ค. 2569 · ลอยตัว)**
- ผู้ใช้สั่ง "ทำแบบไม่มีหลักประกันก่อน"

## การตัดสินใจ

- **D1** เก็บดอกเบี้ยเป็นตาราง `interest_schedule: [{ from_year, rate, note? }]` แทน 2 ช่อง (`_1_2`, `_3_plus`)
  — รองรับกี่ช่วงก็ได้ (แบบมีหลักประกันในอนาคต) · ค่าตั้งต้นใน `GSB_SOLAR_LOAN_DEFAULTS`
- **D2** ค่างวดยังคิดแบบเดิม: เท่ากันทุกเดือน ผ่อนหมดพอดีใน 84 เดือน (ไม่ใช้ "ล้านละ")
- **D3** ใบร่างเก่าที่เก็บแต่ 2 ช่องเดิม (3.5/3.5 ซึ่งเป็นค่าตั้งต้นที่ไม่มีใครแก้ได้) → ใช้ตารางใหม่ ·
  snapshot ที่ส่งอนุมัติแล้ว / PDF ที่อนุมัติแล้ว ไม่เปลี่ยน (ตัวเลขแช่แข็ง + รายงานแสดงแบบ 2 ช่วงเดิมเมื่อไม่มีตาราง)
- **D4** §8 แถว "อัตราดอกเบี้ย" สร้างจากตารางเดียวกับที่คำนวณ → ข้อความกับตัวเลขตรงกันเสมอ
- **D5** ยังไม่ทำ: แบบมีหลักประกัน · หน้าตั้งค่าให้แอดมินแก้อัตรา/MRR (ตอนนี้แก้ที่ `loan-defaults.ts`)
