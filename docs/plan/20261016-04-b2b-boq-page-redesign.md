## เพิ่ม: A+B ผสม (16 ต.ค. — ผู้ใช้ถาม "ถ้าเอา A+B หน้าตาจะเป็นอย่างไร")

แท็บใน mockup "A+B · ผสม" · ภาพ `preview-ab-overview.png` / `preview-ab-items.png`

- โครงแท็บแบบ B: **ภาพรวม** = การ์ดตัวเลข + ต้องจัดการ + สัดส่วนต้นทุน (A) + ต้นทุนเรียงหมวด + ข้อมูลใบ (B)
- **รายการ** = เมนูหมวดค้างซ้าย + การ์ดหมวดพับ/กาง (A) + ค้นหา/ตัวกรอง รอราคา · ราคาเปลี่ยน (B)
- **ตั้งค่าใบ** = ชื่อตัวเลือก · Margin · ส่วนเพิ่มเติม · ช่องตั้งค่า O&M (B)
- แก้จุดอ่อน B: ยอดขาย · บาท/Wp · กำไร ย่ออยู่ที่ header ทุกแท็บ
- เสนอ: Solar B2B เปิดมาเจอแท็บรายการ · ผู้ตรวจสอบเจอแท็บภาพรวม · งานแก้มากกว่า A เล็กน้อย

## ทำจริง: A+B (ผู้ใช้เลือก 16 ต.ค. 69)

หน้า `/b2b/boq/[id]` เท่านั้น · ใช้ข้อมูล/สูตร/API เดิมทั้งหมด (calcBoq · PUT · ออก Rev · Excel · O&M)

- **แถบแท็บค้างใต้ Header**: ภาพรวม · รายการ (จำนวนบรรทัด) · ตั้งค่าใบ — desktop มียอดย่อ (ราคาขาย · บาท/Wp · กำไร) + สถานะบันทึก + ปุ่ม Excel / ออก Rev / บันทึก ·
  มือถือ: แถบแท็บอย่างเดียว ปุ่มอยู่แถบล่างแบบเดิม · ความสูง Header/แถบวัดสด
- เปิดหน้า: **แท็บภาพรวมทุก role** (ผู้ใช้สั่ง 16 ต.ค. — เดิมเสนอ Solar B2B → รายการ)
- **ภาพรวม**: การ์ดตัวเลข (ราคาขาย · ขนาดระบบ/จำนวนแผง · บาท/Wp · กำไร + Margin · ต้องจัดการ) · สัดส่วนต้นทุน (สีผูกหมวด 1 · 2 · 3 · 17 · 18 + อื่นๆ) ·
  ต้นทุนเรียงหมวด · ข้อมูลใบ (โครงการ · Rev · ใบเสนอราคาที่อ้าง · O&M) · ตารางสรุปแบบไฟล์ Excel (BoqSummary เดิม) พับไว้
- **รายการ**: เมนูหมวดค้างซ้าย (ยอด · แท่ง · จุดสถานะ · หมวดว่างเป็นชิป) · การ์ดหมวดพับ/กาง · ค้นหาในใบ + ตัวกรอง รอราคา / ราคาเปลี่ยน / ใส่ราคาเอง ·
  เลขลำดับในหมวดคงเดิมตอนกรอง (ตรงกับข้อความ "หมวด X ลำดับ N") · มือถือซ่อนเมนูซ้าย ใช้ dropdown "ไปที่หมวด"
- **ตั้งค่าใบ**: ชื่อตัวเลือก · Margin · VAT · (ใบไม่ผูกโครงการ: ชื่อ/ลูกค้า/ที่ตั้ง/พิกัด) · ส่วนเพิ่มเติม รวม/ทางเลือก · ช่องตั้งค่า O&M
- ภายหลัง (ยังไม่ทำรอบนี้): บรรทัดเป็นการ์ดบนมือถือ (ปุ่ม − / +) — รอบนี้ตารางเลื่อนซ้ายขวาแบบเดิม

  `formatTHB` แบบ 0 ตำแหน่งไม่ปัดเศษ → ปัดในคอมโพเนนต์ใหม่ (ไม่แตะตัวกลางที่ทั้งแอปใช้) · subtitle ของ Header เป็นตัวพิมพ์ใหญ่ → ย้ายชื่อตัวเลือกไปการ์ดข้อมูลใบ

### ยุบแท็บ "ตั้งค่าใบ" (16 ต.ค. 69 — ผู้ใช้ถามว่ายุบได้ไหม → "ทำเลย")

เหลือ 2 แท็บ **ภาพรวม / รายการ** — ของในแท็บตั้งค่าใบซ้ำกับที่อื่นเกือบหมด ย้ายส่วนที่เหลือไปจุดที่ใช้งาน:
- Margin → การ์ดข้อมูลใบ ใต้ชื่อตัวเลือก (ผู้ใช้เลือกแบบ ข. — การ์ดกำไรแสดงอย่างเดียว ทั้งแถวการ์ดตัวเลขไม่มีช่องกรอก) · VAT → การ์ดราคาขาย (มีอยู่แล้ว) · ช่องตั้งค่า O&M → การ์ดหมวด 13 (มีอยู่แล้ว) + ลิงก์ "ตั้งค่า O&M ›" ในการ์ดข้อมูลใบ
- **ชื่อตัวเลือก** → แก้ได้ในการ์ดข้อมูลใบ (แท็บภาพรวม)
- **รวมในราคา / ทางเลือก** → ปุ่มสลับบนหัวการ์ดหมวดส่วนเพิ่มเติม (แท็บรายการ) · เพิ่มหมวดเสริม = ชิปในเมนูซ้าย (มีอยู่แล้ว)
- ช่องชื่อโครงการ/ลูกค้า/ที่ตั้งของใบไม่ผูกโครงการ → ตัดออก (ใน DB ไม่มีใบแบบนี้ 0/3 · สร้างใบต้องเลือกโครงการ)
- ลบ `BoqSettings.tsx` · ทดสอบ: แท็บ 2 อัน · แก้ชื่อตัวเลือก + สลับหมวด 20 เป็นทางเลือก → ราคาขาย 488,235 → 370,588 → บันทึกแล้วฐานได้ทั้งคู่ · ไม่มี error

### ปรับต่อ (16 ต.ค. 69)

- แถบแท็บสูงคงที่ 52 px (เดิม 50 ↔ 61 px ตามยอดย่อ → เนื้อหากระโดดตอนสลับแท็บ) · สลับแท็บเองแล้วกลับขึ้นบนสุด
- Margin ย้ายจากการ์ดกำไรไปการ์ดข้อมูลใบ (ผู้ใช้เลือกแบบ ข.) — การ์ดตัวเลขทั้งแถวแสดงอย่างเดียว
- การ์ด "ต้องจัดการ" ย้ายลงล่างสุดของแท็บภาพรวม (ผู้ใช้สั่ง) — แถวการ์ดตัวเลขเหลือ 4 · จำนวนยังโชว์บนแท็บภาพรวม · รายการแบ่ง 2 คอลัมน์บนจอกว้าง
- ชื่อการ์ด "ข้อมูลใบ" → **"รายละเอียด BOQ"** (ผู้ใช้เลือกจาก 4 ตัวเลือก 16 ต.ค. 69)
- ชื่อการ์ด "ยอดแยกตามหมวด" → **"สรุปรายหมวด"** และตัดคำอธิบายข้างชื่อออก (ผู้ใช้สั่ง 16 ต.ค. 69) · การ์ดสัดส่วนต้นทุนคงไว้
- แถวการ์ดตัวเลข 4 ใบจัดให้ระนาบเดียวกัน (ผู้ใช้สั่ง 16 ต.ค. 69) — ทุกใบโครงเดียวกัน: ชื่อ → ตัวเลข 28 px → บรรทัดรอง · การ์ดราคาขายต่างแค่พื้นสี ·
  การ์ดต่อวัตต์เปลี่ยนเป็น **"ราคาขาย/Wp"** (เดิมตั้ง "ราคาขายต่อวัตต์" — ผู้ใช้เลือกแบบ ก. ให้ตรงแถบบน) (ต้นทุนต่อวัตต์ย้ายไปบรรทัดรอง) · วัดที่ 1660/1366 px ตัวเลขทุกใบสูงตรงกัน (ต่างไม่เกิน 1 px)

### ปรับแท็บรายการ (16 ต.ค. 69 · ผู้ใช้ให้ตรวจหน้า แล้ว "ทำเลย" ข้อ 1–4)

- **บั๊ก scrollbar แนวนอนใต้ทุกหมวด** — ปุ่ม × (28 px) ล้นคอลัมน์ 32 px ที่มี padding 16 px → ตารางเกินกรอบ 4 px · จอ 1366 ตาราง 820 px เกินที่ว่าง 786 px
  → คอลัมน์ลบ 36 px ไม่มี padding ข้าง · ตารางขั้นต่ำ 780 px · วัดที่ 1911 / 1440 / 1366 ไม่ล้นแล้ว
- ปุ่ม "+ เลือกจาก Master" / "+ ใส่ราคาเอง" ย้ายไปท้ายตาราง (บรรทัดใหม่ต่อท้ายตรงนั้น) · หมวดว่างยังอยู่บนหัวการ์ด
- "+ หมายเหตุ" ต่อท้ายบรรทัดยี่ห้อ · รุ่น (ไม่มีบรรทัดนั้น → อยู่แถวป้ายสถานะ) — แถวที่จอกว้างสูง 67 px จากราว 105 px
- เมนูซ้าย: หมวดที่ยังว่าง = แถวเรียบสีจาง "เลข ชื่อ +" ในกลุ่มพับได้ "ยังไม่มีรายการ (15)" (กางไว้เป็นค่าเริ่มต้น — ผู้ใช้สั่ง 16 ต.ค.) · ส่วนเพิ่มเติมที่ยังไม่ได้เพิ่มพับไว้ "ยังไม่ได้เพิ่ม (7)"
- "ดึงจากใบอื่น" ย้ายขึ้นแถบบนคู่ Excel / ออก Revision (มือถืออยู่แถวเครื่องมือเหมือนเดิม) · ตัวกรองที่เป็น 0 จางและกดไม่ได้ · จอ 1366 แถวเครื่องมือเหลือแถวเดียว
- คำต่อวัตต์ใช้ **"ราคาขาย/Wp"** ทุกจอของ B2B (ผู้ใช้เลือกแบบ ก.) — แถบบน · การ์ดภาพรวม · ตารางหน้ารายการ BOQ · ตารางตัวเลือกในหน้าโครงการ · ตารางสรุปแบบ Excel (คู่กับ "ต้นทุน/Wp") · ไฟล์ Excel ไม่แตะ
- หัวรองแสดง "Rev 0" แทน "REV 0" — Header รับ subtitle เป็น ReactNode ได้ (ห่อ `normal-case` เฉพาะคำ Rev · หน้าอื่นไม่เปลี่ยน)
