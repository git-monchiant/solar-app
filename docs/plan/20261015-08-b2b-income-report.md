# รายรับ B2B — รายงานรับเงินงวดโครงการ B2B ในการ์ดบัญชี

สถานะ: **done** (15 ต.ค. 69) · ต่อจากแผน [20261015-07](20261015-07-b2b-project-flow.md) (ครบ 4 เฟส + แยกการ์ด 3 ใบ)

## ที่มา

ไล่ตรวจว่าการ์ดครอบคลุมงาน B2B หมดหรือยัง (15 ต.ค.) — เส้นทาง 3100–3950 ครบ แต่การ์ดบัญชีมี "รายรับ/ใบแจ้งหนี้" (B2C) กับ "รายรับ O&M"
ไม่มีของ B2B: บัญชียืนยันรับเงินแล้วดูประวัติ/ยอดค้างรับรวมไม่ได้ ต้องเปิดทีละโครงการ · ผู้ใช้ตอบ "ทำตามแนะนำ" (ทำข้อนี้ก่อน แล้ววางแผน O&M B2B)

## ทำอะไร

- เมนู **"รายรับ B2B"** ในการ์ดบัญชี ต่อจาก "รายรับ O&M" → `/report/b2b` (บัญชี/admin)
- ผังยกจากหน้ารายรับ O&M ทั้งก้อน: การ์ดสรุป 4 ช่อง (โครงการ · มูลค่ารวม · รับแล้ว · ค้างรับ) · ค้นหา + ตัวกรอง · ตาราง desktop / การ์ด mobile · Export CSV
- **1 แถว = 1 โครงการที่ได้งาน** (มีงวดเงิน) — แถบเลขงวดระบายสีตามสถานะ · กดแถวกางดูทีละงวด (เงื่อนไข · ยอด · สถานะ · วันลูกค้าชำระ · บัญชียืนยัน · ดูหลักฐาน)
  · ชื่อโครงการลิงก์ไปหน้าโครงการแท็บงวดเงิน (บัญชีเปิดได้แบบอ่านอย่างเดียว — มีอยู่แล้วจากเฟส 3)
- ยอดทุกช่อง **รวม VAT** (ยอดที่ลูกค้าโอนจริง) · ค้างรับ = งวดที่ยังไม่รับเงิน — โครงการที่ยกเลิกไม่นับค้างรับ
- ตัวกรองสถานะ: ยังค้างรับ · มีงวดถึงกำหนดวางบิล · รอบัญชียืนยัน · รับครบแล้ว · ช่วงวันที่ = วันได้งาน
- **CSV ออกทีละงวด** (โครงการ · บริษัท · เลขผู้เสียภาษี · เลข PO/สัญญา · ใบเสนอราคา · งวด · ก่อน VAT · VAT · รวม · สถานะ · วันที่) — ใช้ลงบัญชีได้ตรง
- ยืนยัน/ตีกลับยังทำที่หน้ารอยืนยันรับเงิน (ส่วน B2B) เหมือนเดิม — หน้านี้ดูอย่างเดียว

## ไฟล์

- API `src/app/api/b2b/report/income/route.ts` (account/admin)
- หน้า `src/app/(app)/report/b2b/page.tsx` · เมนู `src/lib/modules.tsx` (การ์ดบัญชี)
- `src/lib/b2b/project-server.ts`: แยก `INSTALLMENT_SELECT` + `toInstallment` ให้หน้าโครงการกับรายงานใช้ชุดเดียวกัน

## ทดสอบ

- Solar B2B / Purchase เรียก API → 403
- 3 โครงการทดสอบ (ขั้น 3600 · 3700 มีงวดถึงกำหนด · ปิดโครงการรับครบ): ยอดรวม/รับแล้ว/ค้างรับ ตรงกับหน้าโครงการ · ผลรวมงวด = มูลค่าสัญญา × (1 + VAT)
- หน้าจอมุมบัญชี desktop + มือถือ ไม่มี error · ลบข้อมูลทดสอบแล้ว
