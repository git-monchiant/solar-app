## หน้าตาขั้น 03 (ขั้นที่กำลังทำ · `OmPaymentPanel steps`)

- แถบขั้นย่อย `StepLayout` ตัวเดียวกับ OrderStep: **เลือกใบเสนอราคา · ชำระเงิน** (O&M ไม่มีงวด/นัดหมาย/ยืนยันในขั้นนี้ — นัดหมายเป็นขั้น 04 อยู่แล้ว)
- ขั้นย่อย 1 — ยกจาก Step 0 ของ OrderStep:
  กล่องส้มการ์ดชุด (ชุด N · ลิงก์ PDF ชื่อ `เลขใบ_ชื่อลูกค้า.pdf` · ยอด · เลขใบ · ป้าย "เลือกแล้ว") + ป้ายล็อกเมื่อแนบสลิปแล้ว + บันทึกถึงฝ่ายขาย
  · กล่องส่วนลด **ล็อกเสมอ** "🔒 ข้อมูลจากใบเสนอราคาที่อนุมัติแล้ว" (O&M ให้ส่วนลดในใบเท่านั้น) · กล่องยอดรวม / ส่วนลด % · เหตุผล / ยอดชำระสุทธิ · ปุ่ม **ถัดไป ›**
- ขั้นย่อย 2 — แบบ Step 1 ของ OrderStep: กล่องส้ม "ใบเสนอราคาที่ลูกค้าเลือก" · ช่องยอดใหญ่ (อ่านอย่างเดียว) · ฟอร์มแนบสลิปเดิม / สถานะรอ Account / ยืนยันแล้ว + ใบเสร็จ
  · ปุ่ม **‹ ย้อนกลับ** + **ส่งให้ Account ยืนยัน** (ปุ่มหลักขั้นสุดท้ายแบบ OrderStep)
- เปิดใบงานที่แนบสลิปแล้ว → ไปขั้นย่อยชำระเงินให้เอง · ขั้นที่ปิดแล้ว (กางดู) คงหน้าตาเดิม
- **เอาแถบ "ลูกค้าไม่เอา — ยกเลิกงานนี้" ออกจากขั้น 03** (ผู้ใช้สั่ง "เอากรอบแดงออก") — ขั้น 02 เอาออกไปก่อนแล้ว (แผน 09)
  ⇒ ใบงานทั่วไปไม่มีปุ่มยกเลิกบนหน้ารายละเอียดแล้ว (ใบซ่อมยังมีที่แถบบนสุด · API `/cancel` ยังอยู่)

## แก้ที่ไหน

| ไฟล์ | แก้ |
|---|---|
| `api/om/quotations/[id]/send` | ขั้นเสนอราคา = handoff (ตั้งชุดที่ส่งมาเป็นชุดที่เลือก + ไปขั้นชำระเงิน · log `to.handoff`) · ขั้นชำระเงิน = เปลี่ยนชุด (ล้าง sent_to_customer_* ของชุดอื่น · มีสลิปแล้ว 409 · กดชุดเดิม = ไม่ทำอะไร) |
| `OmQuotationPanel` | ปุ่มยาว = /send ของชุดแรก · เอาการแตะเลือกการ์ดของแผน 09 ออก · ป้ายการ์ด "เลือกแล้ว" · ข้อความหัวแผงแบบฝั่งขาย ("ลูกค้าจะเลือก 1 ฉบับในขั้นชำระเงิน") |
| `OmPaymentPanel` | เพิ่ม `steps` + `PaySteps` (ขั้นย่อย) · แยก `PayStatus` ใช้ร่วมกับมุมมองขั้นที่ปิดแล้ว |
| `JobDetail` | ขั้น 03 ที่กำลังทำ วาง `OmPaymentPanel steps` บนพื้นการ์ด (ไม่ห่อ SECTION) · ลบ declineBox |
| `booking-log` · `JobTimelineTab` | ป้าย handoff = "ส่งใบเสนอราคาให้ทีมขาย" · เปลี่ยนชุดที่ขั้นชำระเงิน = "ลูกค้าเลือกใบเสนอราคาชุด N" อยู่ช่วงชำระเงิน |

ไม่มี migration · ข้อมูลเก่า (เลือกชุดที่ขั้น 02 ไปแล้ว) ใช้ต่อได้ทันที
