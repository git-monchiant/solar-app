# Package O&M — เปิดการ์ดหมวด SETUP

ผู้ใช้สั่ง 24 ก.ย. 69: เปิดการ์ด "Package O&M" (เดิมเป็น "เร็วๆ นี้") ใส่ตารางค่าบริการ O&M
โดยคงรูปแบบ เมนู ฟังก์ชัน ธีม ฟอนต์ ให้เหมือนการ์ด Package

| ขนาดติดตั้ง | แผงไม่เกิน | รายครั้ง | สัญญา 12 เดือน เข้า 2 ครั้ง |
|---|---|---|---|
| 2.00–5.00 kW | 10 | 2,200 | 3,500 |
| 5.01–10.00 kW | 20 | 3,000 | 5,000 |
| 10.01–20.00 kW | 50 | 4,000 | 6,000 |

ขอบเขตงาน: รายครั้ง = ล้างแผง+ตรวจสอบระบบ+ออกใบงานแจ้งผล · สัญญา = + ตรวจเช็คตามการแจ้งซ่อมระหว่างสัญญา
หมายเหตุท้ายตาราง 2 ข้อ (ไม่รวมค่าวัสดุ · เก็บค่าบริการก่อนนัดหมาย)
