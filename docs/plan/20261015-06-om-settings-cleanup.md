## สิ่งที่ทำ

1. คีย์ที่ไม่มีผลเข้า `RETIRED` (ไม่ลบแถวในฐาน ตามกติกาเดิม)
2. เพิ่มกลุ่ม "การโทรติดตามลูกค้า" (call.* 3 ค่า) — ไม่ติดป้าย "รอ business ยืนยัน" (ผู้ใช้สั่งเอาออก ถึง `pending_biz = 1` ในฐาน)
3. เอากล่องเหลือง "รอ business ตอบ" ออกทั้งกล่อง (ผู้ใช้สั่ง) — 3 คีย์ cancel/no-show ไม่แสดง เพราะไม่มีโค้ดอ่าน
4. จัดหน้า: การ์ดเรียงเป็นคอลัมน์ (1 / 2 / 3 คอลัมน์ตามความกว้าง) แทนแถวเต็มจอที่ป้ายกับช่องกรอกห่างกันมาก ·
   true/false เป็นสวิตช์ (ยกจาก payment-setup) · ตัวเลขมีหน่วยในช่อง · ซ่อน key เทคนิคไว้ใน tooltip ·
   รวบรอบดึง REM เป็นชั่วโมงให้อ่านง่าย
5. คีย์ใหม่ที่ไม่รู้จักไปกลุ่ม "อื่น ๆ" — ไม่หายเงียบแบบ call.* อีก
6. แท็บคิวจับคู่ (หน้า `/om/match-queue`): เอากล่องเหลืองอธิบาย "ระบบจะไม่เดาให้ …" ออก (ผู้ใช้สั่ง)
7. ซ่อนแท็บ "ใบตรวจรับงาน" (ผู้ใช้สั่ง) — ซ่อนแค่แท็บ · JobFormsTab + `/api/om/job-forms` ยังอยู่ · ช่างกรอกขั้น 05 / กันปิดงานไม่ครบ / PDF อ่านใบจากฐานตรง ไม่กระทบ

ไม่มี migration · ไม่แตะ API
