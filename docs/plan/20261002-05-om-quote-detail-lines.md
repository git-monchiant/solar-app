# ใบเสนอราคา O&M — เพิ่ม/ลด/แก้ "รายละเอียด" ใต้หัวข้อ แบบฝั่งขาย

ที่มา: ผู้ใช้ส่งภาพ popup ฝั่งขาย (แพ็กเกจกางรายการอุปกรณ์ + "+ เพิ่มรายละเอียด" / "↺ คืนค่าจาก Master") 2 ต.ค. 69
"ทำตามตัวอย่างที่เพิ่ม ลด รายละเอียดได้" · ต่อจาก [20261002-04](20261002-04-om-quote-editor-like-sales.md)
ผู้ใช้เคาะ: **งวดชำระคงเดิม** (1 งวด ชำระเต็มก่อนนัด ล็อกไว้) — ขอเพิ่มงวดได้ไว้ก่อน ยังไม่ทำ
(ค้าง: ถ้าเปิดหลายงวด ขั้น 03 ต้องรู้ว่าเก็บงวดไหนก่อนนัด — ตอนนี้ API รับเงินบังคับยอดเต็มก้อนเดียว)

สถานะ: **เสร็จ 2 ต.ค. 69**

## ทำอะไร

- ทุกหัวข้อ (แพ็กเกจ + งานเพิ่ม) มี ▸ กาง/หุบ (ทีละหัวข้อแบบฝั่งขาย) · บรรทัดรายละเอียด ชื่อ/จำนวน/หน่วย ไม่มีราคา · "+ เพิ่มรายละเอียด" · × ลบ
- แพ็กเกจ: รายละเอียดตั้งต้น = ขอบเขตงานของ Package O&M แยกบรรทัดตาม "+" (แทนรายการอุปกรณ์จาก Package Master ของฝั่งขาย)
  เลือก/เปลี่ยนแพ็กเกจ = ดึงใหม่ · "↺ คืนค่าจาก Master" = ดึงใหม่ · ใบเก่าที่แก้ = ใช้ที่เก็บไว้ (ใบเก่าไม่มีรายละเอียด)
- เก็บ: `quotation_items.source_type = 'custom_detail'` ราคา 0 ต่อท้ายหัวข้อของตัวเอง (ชนิดเดียวกับรายละเอียดงานเพิ่มฝั่งขาย)
  แพ็กเกจไม่ได้เก็บเป็นแถว ⇒ รายละเอียดที่อยู่**ก่อน**หัวข้องานเพิ่มตัวแรก = ของแพ็กเกจ
- PDF: ตัวเรนเดอร์เดิมรองรับอยู่แล้ว (custom_detail → "- ชื่อ จำนวน หน่วย" ใต้หัวข้อ ไม่มียอด) · `omDocumentItems` ไม่ต่อจำนวน/หน่วยให้บรรทัดรายละเอียด (ตัวเรนเดอร์ต่อเอง)
- ใบเสร็จ O&M (`receipt/data` ทาง om) ไม่เอาบรรทัดรายละเอียด — เดิมพิมพ์ทุกแถวพร้อมยอด จะได้แถว 0.00
- การ์ดใบ: "รายการเสริม" นับเฉพาะหัวข้อ

## ไม่ทำ

- งวดชำระหลายงวด (ผู้ใช้ให้คงเดิม) · ไม่มี migration

## ตรวจ

- tsc · eslint · API สร้างใบที่มีรายละเอียดทั้งแพ็กเกจและงานเพิ่ม → อ่านกลับ/ตัวอย่าง PDF/PDF ใบจริง · หน้าจอกาง/เพิ่ม/ลบ/พิมพ์ไม่หลุดโฟกัส · ลบข้อมูลทดสอบ

## บันทึกการทำ (2 ต.ค. 69)

- ทำครบตามหัวข้อ "ทำอะไร" · `DetailRows` อยู่นอก QuoteEditor (ประกาศข้างในจะ mount ใหม่ทุกครั้งที่พิมพ์ ช่องหลุดโฟกัส)
  · ปุ่ม × ของบรรทัดรายละเอียด จอใหญ่โผล่ตอนชี้แถวแบบฝั่งขาย มือถือโชว์ตลอด
- ผลตรวจ: tsc / eslint ผ่าน · ไม่มี console error · ลองบนบ้าน 311/77 แล้วลบทิ้ง (ใบงาน #139)
  - API: บันทึกรายละเอียดแพ็กเกจ 2 + งานเพิ่ม 1 (มีรายละเอียด 2) → อ่านกลับตามลำดับ · ราคาที่ส่งมากับบรรทัดรายละเอียด (999) ถูกบังคับเป็น 0 · ยอด 4,200 ถูก
    · ไม่มีแพ็กเกจแต่ขึ้นต้นด้วยรายละเอียด = 400
  - PDF ใบจริง: "- ล้างแผง" "- ตรวจสอบระบบ" ใต้แพ็กเกจ · "- สาย PV1-F 4 sq.mm. 10 เมตร" "- ขั้วต่อ MC4 4 คู่" ใต้งานเพิ่ม ไม่มียอด
  - หน้าจอ: แก้ใบ → ▸ แพ็กเกจกางรายละเอียด 2 บรรทัด + ปุ่มเพิ่ม/คืนค่า · พิมพ์ต่อท้ายไม่หลุดโฟกัส · เพิ่มบรรทัดได้ · ▸ งานเพิ่มกางรายละเอียดของตัวเอง (ทีละหัวข้อ)
- ข้อสังเกต: ขอบเขตงานพิมพ์ 2 ที่ (รายละเอียดใต้แพ็กเกจ + หัวข้อ "1. ขอบเขตงาน" ท้ายใบ) — ถ้าไม่ต้องการ เอาหัวข้อท้ายใบออกได้
