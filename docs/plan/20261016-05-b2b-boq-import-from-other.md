# BOQ: ใช้ใบงานอื่นเป็นต้นแบบให้ยืดหยุ่นขึ้น — เลือก Rev เก่า · ดึงบางหมวดเข้าใบที่ทำอยู่

สถานะ: **done** (16 ต.ค. 69) — ทำครบ 3 ข้อ · ทดสอบ 12 ข้อผ่าน

## ที่มา

16 ต.ค. 69 ผู้ใช้ถาม "ถ้าเคยมี BOQ งานอื่นที่ใกล้เคียง เลือกแล้วมาปรับในใบใหม่ได้ไหม" → ได้ (คัดลอกตอนสร้าง แผน 20261016-02)
แต่มีข้อจำกัดที่เสนอไว้ · ผู้ใช้ "ทำตามแนะนำ"

## ทำ

1. **ช่อง "เริ่มจาก" เลือก Rev เก่าได้** — เดิมมีแค่ Rev ล่าสุดของแต่ละเลขที่ (API คัดลอกรับทุก Rev อยู่แล้ว) · Rev ล่าสุดขึ้นก่อน Rev เก่าต่อท้ายในเลขที่เดียวกัน
2. **ดึงหมวดจากใบอื่นเข้าใบที่ทำอยู่** — แท็บรายการ ปุ่ม "ดึงจากใบอื่น" → เลือกใบ (Rev ไหนก็ได้) → ติ๊กหมวด → เพิ่มต่อท้าย หรือแทนที่ของเดิมในหมวดที่เลือก
   - กติกาเดียวกับคัดลอกทั้งใบ: บรรทัด Master ใช้ราคาปัจจุบัน · ราคาใส่เองคัดลอกตามเดิม · หมายเหตุติดมา
   - รายการที่ปิดใช้งานใน Master แล้ว **ข้าม** (ใบที่ทำอยู่เพิ่มรายการปิดใช้งานใหม่ไม่ได้ — API บันทึกปฏิเสธ) + แจ้งจำนวน
   - หมวด 13 O&M: บรรทัดสูตรที่ใบมีอยู่แล้ว (role ซ้ำ) ไม่ดึงซ้ำ · ใบยังไม่มีช่องตั้งค่า → ใช้ช่องตั้งค่าของใบต้นทาง
   - หมวดเสริม: ติดโหมด รวมในราคา/ทางเลือก ของใบต้นทางมา (ถ้าใบที่ทำอยู่ยังไม่มีหมวดนั้น)
   - ทำในหน้าจอ ยังไม่บันทึกจนกด "บันทึก" (server ตรวจซ้ำตามปกติ) · ไม่มี API ใหม่
3. **คัดลอก/ดึงข้ามโครงการ → ระยะทาง O&M เป็น 0** — ระยะทางเป็นของไซต์เดิม · ขึ้นเตือนใน "ต้องจัดการ" ให้กรอกใหม่ (ช่องอื่นของ O&M คงเดิม)

## ทดสอบ

- เลือก Rev เก่าเป็นต้นแบบ → ได้บรรทัดของ Rev นั้น
- ดึง 2 หมวดแบบต่อท้าย / แบบแทนที่ → จำนวนบรรทัดถูก · รายการปิดใช้งานถูกข้าม · บันทึกผ่าน
- คัดลอกข้ามโครงการ → om_params.distance_km = 0 · โครงการเดียวกัน → คงระยะทาง
