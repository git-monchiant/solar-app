# พักใบงานซ่อม O&M ไว้ก่อน

ที่มา: ผู้ใช้สั่ง 14 ต.ค. 69 "ยกเลิกงานซ่อมก่อน" (ชี้กล่อง "ช่างไม่ได้แจ้งงานซ่อม · พบปัญหาภายหลัง? เปิดใบงานซ่อม ›" ในขั้น 06 ปิดงาน)

สถานะ: **เสร็จ 14 ต.ค. 69**

## ทำ

สวิตช์เดียว `OM_REPAIR_ENABLED = false` ใน `src/lib/om/service-view.ts` ซ่อนทางเข้าใบงานซ่อมบนหน้าจอทั้งหมด:
- ขั้น 06 ปิดงาน: กล่องเปิดใบงานซ่อม (รวมแถบ "⚠ ช่างแจ้งพบงานซ่อม — ยังไม่เปิดใบงานซ่อม")
- ใบตรวจของช่าง: ช่อง "พบงานซ่อม · ทีม O&M เปิดใบงานซ่อมต่อให้" (ซ่อนด้วย เพราะไม่มีใครเปิดใบซ่อมต่อให้แล้ว)
- การ์ดในรายการงานบริการ: ชิปเตือนรอเปิดใบงานซ่อม (`repairPending`)

## ไม่แตะ

- ข้อมูลเดิม (`repair_needed` / `repair_detail` ในใบตรวจ) · ใบเสร็จบริการ PDF ยังพิมพ์ "พบงานซ่อม" ของใบเก่า
- ใบงานซ่อมที่เปิดไว้แล้ว — แถบใบงานซ่อม + ปุ่มยกเลิกใบงานซ่อมยังอยู่ ทำงานต่อจนจบได้
- API (`/api/om/bookings/[id]/repair` ฯลฯ) · ไม่มี migration
- เปิดกลับ = เปลี่ยนสวิตช์เป็น `true` ที่เดียว
