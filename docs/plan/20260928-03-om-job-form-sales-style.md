# ใบตรวจรับงาน O&M — โครง + หน้าตาเหมือนขั้นติดตั้งฝั่งขาย

ผู้ใช้สั่ง 28 ก.ย. 69 ("ตามแนะนำ ให้เหมือนโครงของขั้นติดตั้งฝ่ายขาย") หลังเทียบภาพขั้น 05 เข้างาน (O&M) กับขั้น 05 Install (lead)
สถานะ: **เสร็จ 28 ก.ย. 69**

## ปัญหา

- การ์ดขั้นของ O&M ใช้คลาสฝั่งขายอยู่แล้ว แต่ใบตรวจข้างใน (`components/om/JobFormPanel.tsx`) ยังเป็นสไตล์หน้าช่างเดิม
  พื้นเทา · แถบหัวขาว sticky · บีบกลาง `max-w-[1400px]` · การ์ด `rounded-2xl` หัวแถบเทา · ปุ่ม ✓/✗ · หน่วยอยู่นอกช่อง
- ทั้งใบยาวเป็นหน้าเดียว 2 คอลัมน์ ไม่มีขั้นย่อยแบบขั้นติดตั้ง

## ทำอะไร (ยกของเดิมทั้งก้อน ไม่ออกแบบใหม่)

1. **แถบขั้นย่อย** = `StepLayout` ตัวเดียวกับ `InstallStep` · 3 ขั้น: **ตรวจ** / **รูป · บันทึก** / **ส่งมอบ**
   - จำขั้นที่เปิดไว้ด้วย `useSubStep` (key `omJobSubStep_<id>`) เหมือนฝั่งขาย
   - ปุ่มท้าย = ย้อนกลับ / ถัดไป แบบ `InstallStep` (h-11 · md:w-64) + ปุ่มบันทึกร่าง · ขั้นสุดท้ายเป็นปุ่มปิดงาน
   - **ไม่บันทึกอัตโนมัติตอนกดถัดไป** — PUT report เขียน activity log (`check`) ทุกครั้ง จะรก timeline
   - ข้อมูลกรอกไม่ต้องบันทึกก่อนเปลี่ยนขั้นย่อย (state อยู่ที่ตัวใบ ไม่หายตอนสลับ)
2. **กล่อง/หัวข้อ** = คลาสของ `InstallChecklist` (กรอบม่วงอ่อน · หัวข้ออังกฤษตัวใหญ่ + ไอคอน · ต่อท้ายชื่อไทย)
   - ขั้นตรวจ: DOCUMENT HEADER · VISUAL INSPECTION (คุณภาพงาน) · FUNCTION TESTS (การทดสอบระบบ)
   - ขั้นรูป · บันทึก: PHOTOS (ก่อน/หลัง) · NOTES · REPAIR (พบงานซ่อม)
   - ขั้นส่งมอบ: RESULT (ผล + วิธีปิดงาน) · SIGNATURES
3. ข้อ bool = แถว "ชื่อข้อ | ผ่าน | ไม่ผ่าน | หมายเหตุ" แบบ VISUAL INSPECTION (กดซ้ำ = ยกเลิกเลือก)
   ช่องหมายเหตุเก็บใน `checks[code].fix` เดิม (ไม่มีที่อื่นอ่าน fix นอกจากใบนี้ — ตรวจแล้ว)
4. ข้อ num = `MeasureField` ของ `InstallChecklist` (ป้ายชิดขวา · หน่วยอยู่ในช่อง · 2 ช่องต่อแถว)
5. รูป = กล่องลากวาง/แตะเลือกแบบ HANDOVER PHOTOS (รูปจัตุรัส + ช่อง +) · ยังเปิดกล้องหลังบนมือถือเหมือนเดิม
6. เงื่อนไขขาดข้อมูลแจ้งด้วย `ErrorPopup` ตัวเดียวกับฝั่งขาย (ไม่เซ็น · ติ๊กพบงานซ่อมแต่ไม่เล่าอาการ)
7. ฝังใน `JobDetail` ไม่ห่อ SECTION ซ้อนแล้ว — ใบวางตรงในการ์ดขั้นแบบ `InstallChecklist` ในการ์ด Install
8. แผ่นเซ็นวาดลายเซ็นที่บันทึกไว้กลับขึ้นมาตอนเปิดใบ (เดิมใบที่เซ็นแล้วเปิดใหม่เห็นกรอบว่าง) + ใบปิดแล้วเซ็นทับไม่ได้

## ไม่ทำ

- ไม่แตะ API / ฐานข้อมูล / state machine ปิดงาน
- หน้าช่างเต็มจอ `/om/field/[id]` ใช้ไฟล์เดียวกัน ได้โครงใหม่ไปด้วย แต่คงแถบหัว + ปุ่มกลับไว้

## ตรวจ (28 ก.ย. 69 บน solardb_v3)

- `npx tsc --noEmit` + eslint 2 ไฟล์ผ่าน · `/om/field/11` `/om/services/13986` ตอบ 200
- ถ่ายจอ puppeteer ใบงาน #11 ครบ 3 ขั้นย่อย: หน้ารายละเอียด 1600px · หน้าช่าง 1440px · มือถือ 390px — ไม่มี runtime error
- ยังไม่ได้กดบันทึกร่าง/ปิดงานจริงในรอบนี้ (ไม่อยากเขียน Activity log ใบทดสอบ) — ตรรกะ save/ปิดงานไม่ได้แก้ แก้แค่ปุ่มปิดงานเปลี่ยนจาก disabled เป็นเด้ง ErrorPopup เมื่อยังไม่เซ็น
