# Quotation Package Options Mockup

## Status

`done`

## Objective

ออกแบบหน้า Step 03 Quotation ให้ผู้ใช้สร้างใบเสนอราคาได้สูงสุด 3 ฉบับ โดยแต่ละฉบับเลือกแพ็กเกจหลักและตัวเลือกเพิ่มเติมได้อิสระ พร้อมคงโทนสี ปุ่ม และโครงสร้างหน้าจอเดิมของ Solar V0

## Scope

- แสดง Quotation 3 ชุดในหน้าเดียว
- รองรับสถานะว่าง ฉบับร่าง และพร้อมส่ง
- แสดงแพ็กเกจหลัก Add-on ยอดสุทธิ และเลขที่เอกสาร
- ยึดรายละเอียดอุปกรณ์มาตรฐานจาก Package Master และล็อกแหล่งที่มาเป็น Package
- เพิ่มอุปกรณ์หรือบริการนอกแพ็กเกจได้ โดยระบุชื่อ จำนวน และราคา
- มีปุ่มสร้าง แก้ไข คัดลอก ดู PDF และส่งใบเสนอราคา
- แสดงเงื่อนไขว่าขั้น Order จะเลือกได้เพียง 1 ฉบับ
- ทำเป็น interactive HTML mockup และภาพ preview สำหรับตรวจแบบ

## Out of Scope

- ยังไม่เชื่อมฐานข้อมูลหรือ API จริง
- ยังไม่สร้าง PDF จริง
- ยังไม่แก้โค้ด production ของหน้า Lead

## Acceptance Criteria

- หน้าตาและสัดส่วนใกล้เคียงหน้าต้นฉบับที่ผู้ใช้ส่งมา
- เห็นความแตกต่างของใบเสนอราคา 3 ชุดได้ชัดเจน
- ทดลองกดสร้างชุดที่ 3 คัดลอก ดู PDF และเลือกใบเสนอราคาสำหรับส่งได้
- เปิดดูได้จาก `docs/mockup/20260720-02-quotation-package-options/index.html`
