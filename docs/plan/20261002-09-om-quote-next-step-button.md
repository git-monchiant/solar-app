# ขั้น 02 O&M — ไปขั้นถัดไปด้วยปุ่มยาวใต้การ์ด แบบฝั่งขาย

ที่มา: ผู้ใช้ขอ 2 ต.ค. 69 "ปรับงาน การกด ไป step ต่อไปให้ เหมือน งานขายดังรูป"
(ภาพขั้น 03 Quotation ฝั่งขาย — การ์ดอนุมัติแล้วมี "ดูใบเสนอราคา" + "Revision" · ปุ่มยาวไล่สี "▷ ส่งใบเสนอราคาให้ทีมขาย")
ต่อจาก [20261002-02](20261002-02-om-quote-three-options.md)

สถานะ: **เสร็จ 2 ต.ค. 69** — การแตะเลือกชุดที่ขั้น 02 ถูกแทนด้วย [แผน 10](20261002-10-om-payment-like-order-step.md) (เลือกชุดที่ขั้น 03 แบบขั้น Order ฝั่งขาย)

## ก่อนแก้

อนุมัติครบแล้ว การ์ดแต่ละชุดมีปุ่มที่ 3 "✓ ลูกค้าเลือก" (= ไปขั้นชำระเงิน) + กล่องเขียวบอกให้กดปุ่มนั้น — ไม่มีปุ่มยาวด้านล่าง

## หลังแก้ (`OmQuotationPanel.tsx` ไฟล์เดียว)

| | ฝั่งขาย | O&M |
|---|---|---|
| ปุ่มในการ์ดที่อนุมัติแล้ว | ▣ ดูใบเสนอราคา · Revision | เหมือนกัน (เอา "✓ ลูกค้าเลือก" ออก) |
| ปุ่มยาวเมื่ออนุมัติครบ | ▷ ส่งใบเสนอราคาให้ทีมขาย → ขั้น Order (ลูกค้าเลือกชุดที่นั่น) | **▷ ส่งใบเสนอราคาให้ทีมขาย** คำเดียวกันเป๊ะ (ผู้ใช้สั่ง "ใช้คำตามกรอบแดง") → ขั้นชำระเงิน |
| เลือกชุด (หลายชุด) | แตะการ์ดในกล่องเลือกชุดขั้น Order (กรอบเขียว + ป้าย "เลือกแล้ว") | แตะการ์ดที่ขั้น 02 (กรอบเขียว + ป้าย "เลือกชุดนี้") ยังไม่บันทึกจนกดปุ่มยาว · ยังไม่แตะแล้วกดปุ่ม = popup "เลือกชุดที่ลูกค้าเลือกก่อน" |
| ไม่ใช่ Sale | — | ปุ่มคำเดียวกัน จางกดไม่ได้ |

- กดปุ่มยาว = dialog ยืนยัน (หัว "ส่งใบเสนอราคาให้ทีมขาย" · บอกชุด/ยอดที่ลูกค้าเลือก) → `/api/om/quotations/[id]/send` เดิม (ไม่แตะ API/ข้อมูล)
- ยังเลือกชุดที่ขั้น 02 ตามกติกาแผน 02 (O&M ไม่มีขั้น Order) — ไม่ได้ย้ายไปเลือกที่ขั้นชำระเงิน
- ปุ่มในการ์ด (ดู PDF / Revision) ไม่นับเป็นการแตะเลือกชุด

## เพิ่ม: เอาแถบ "ลูกค้าไม่เอา — ยกเลิกงานนี้" ออกจากขั้น 02 (ผู้ใช้สั่ง "ยกเลิกกรอบแดง")

- `JobDetail.tsx` — การ์ดขั้น 02 ไม่วาง `declineBox` แล้ว · ขั้น 03 เอาออกตามมาในแผน 10 · ใบงานซ่อมยังยกเลิกได้จากแถบใบซ่อมบนสุด
- ผลข้างเคียง: ใบงานทั่วไปที่ค้างขั้น 02 ยกเลิกจากหน้านี้ไม่ได้แล้ว (Follow-up ไม่มีตัวเลือกยกเลิก) — API `/api/om/bookings/[id]/cancel` ยังอยู่
