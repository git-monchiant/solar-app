# ใบเสนอราคา O&M: เตือนเมื่อแพ็กเกจไม่ตรงขนาดระบบของบ้าน

ที่มา: ผู้ใช้ถาม 14 ต.ค. 69 (รูปใบ "ขนาด 1.28 kW" + แพ็กเกจ 2.00–5.00 kW) "มีการตรวจสอบความเหมาะสมกับ package ไหม
ระบบเดิม 1.28 kW ถ้าเลือก package น้อยเกินหรือมากเกินจะเป็นอย่างไร"

สถานะ: **เสร็จ 14 ต.ค. 69**

## ตอนนี้

- ไม่มีการตรวจที่บังคับ — ใบใหม่เลือกแพ็กเกจรายครั้งที่ช่วง kW ครอบขนาดบ้านให้ก่อน + ป้าย "ตรงกับบ้านนี้" ในหน้าต่างเลือกแพ็กเกจ
  นอกนั้น Sale เลือกช่วงไหนก็บันทึกได้ server ไม่ตรวจ · ด่านเดียวคือผู้อนุมัติต้องสังเกตเอง
- ขนาดบ้านในทะเบียน O&M (1,828 หลัง): 2–20 kW 1,490 · **ต่ำกว่า 2 kW 80** (เล็กสุด 1.15 — ไม่มีช่วงตรง ระบบไม่เลือกให้)
  · **เกิน 20 kW 11** (ใหญ่สุด 28.8 — ไม่มีแพ็กเกจรองรับ) · ไม่มีข้อมูลขนาด 247

## ผู้ใช้เคาะ (14 ต.ค. 69)

1. บ้านต่ำกว่า 2 kW = ตรงกับแพ็กเกจเล็กสุด (ชื่อแพ็กเกจมี "หรือจำนวนแผงไม่เกิน 10 แผง")
2. บ้านเกิน 20 kW = ใช้แพ็กเกจ 10.01–20.00 kW แล้วใส่ส่วนเกินเป็น "งานเพิ่ม"
3. แพ็กเกจไม่ตรงขนาด = **เตือนอย่างเดียว** ไม่ต้องใส่เหตุผล ไม่บล็อก (server ไม่ตรวจ)

## ทำอะไร

- `lib/om/packages.ts` — `omFitTier(pkgs, kw)`: ช่วงที่ตรงกับบ้านตามกติกาข้างบน (ครอบ = ตรง · เล็กกว่าช่วงแรก = ช่วงแรก
  · ใหญ่กว่าช่วงสุดท้าย = ช่วงสุดท้าย + `over`) · ไม่มีขนาดบ้าน = null
- popup ทำใบ (OmQuotationPanel):
  - ใบใหม่เลือกแพ็กเกจรายครั้งของช่วงที่ตรงให้ก่อน — บ้าน < 2 kW / > 20 kW ได้แพ็กเกจให้ด้วย (เดิมไม่ได้)
  - ป้าย "ตรงกับบ้านนี้" ในหน้าต่างเลือกแพ็กเกจใช้กติกาเดียวกัน
  - กล่องเตือนเหนือรายการ: แพ็กเกจที่เลือกไม่ตรงช่วง ("บ้านนี้ 8 kW — แพ็กเกจที่ตรงคือ 5.01–10.00 kW")
    · บ้านเกินช่วงใหญ่สุด + เลือกช่วงใหญ่สุดแล้ว = บอกให้เพิ่มงานเพิ่มสำหรับส่วนเกิน · ไม่มีข้อมูลขนาด = บอกให้ตรวจเอง
- ไม่แตะ server / PDF / คิวอนุมัติ · ไม่มี migration

## ตรวจ

- tsc · eslint · ถ่ายจอ popup: ตรงช่วง (ไม่มีกล่องเตือน) · เลือกผิดช่วง · บ้าน < 2 kW · บ้าน > 20 kW · ไม่มีข้อมูลขนาด

## บันทึกการทำ (14 ต.ค. 69)

- ทำครบตาม "ทำอะไร" · เพิ่มระหว่างทาง: หน้าต่างเลือกแพ็กเกจตัดขอบเขตงานเหลือ 2 บรรทัด (`line-clamp-2`)
  — ขอบเขตงานยาวขึ้นตามแผน 20261014-04 ทำให้รายการยาวจนเทียบ 6 แพ็กเกจในจอเดียวไม่ได้
- ผลตรวจ: tsc / eslint ผ่าน
  · `omFitTier` กับแพ็กเกจจริง 6 ตัว: 0 → null · 1.28 / 2 / 2.24 / 5 → 2.00–5.00 · 5.005 / 8 → 5.01–10.00 · 20 → 10.01–20.00
    · 28.8 → 10.01–20.00 + over
  · ถ่ายจอ (บ้าน 2.24 kW ใบร่างของผู้ใช้ — เปิดดูอย่างเดียว ไม่บันทึก): เปลี่ยนเป็น 5.01–10.00 kW ขึ้นกล่องเตือน
    "บ้านนี้ขนาด 2.24 kW — แพ็กเกจที่ตรงคือ 2.00–5.00 kW (เลือกอยู่ 5.01–10.00 kW)" ปุ่มบันทึกยังกดได้
    · หน้าต่างเลือกแพ็กเกจมีป้าย "ตรงกับบ้านนี้" ที่ 2.00–5.00 kW · ไม่มี console error
  · กรณี < 2 kW / > 20 kW / ไม่มีข้อมูลขนาด ตรวจผ่านฟังก์ชัน (ไม่มีบ้านขนาดนั้นอยู่ขั้นเสนอราคาบนฐาน v3 ให้ถ่ายจอ)
- 15 ต.ค. ผู้ใช้สั่ง "เอาข้อความรายละเอียดออก ใน modal เหลือแค่หัวข้อพอ" — หน้าต่างเลือกแพ็กเกจเหลือชื่อแพ็กเกจ + ราคา
  (ขอบเขตงานเห็นหลังเลือก เป็นรายละเอียดใต้แพ็กเกจ · ช่องค้นหายังค้นจากขอบเขตงานได้)
