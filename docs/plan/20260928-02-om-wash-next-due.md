# บอก "ครบรอบล้างถัดไป" คู่กับสิทธิ์คงเหลือ — ทะเบียนบ้าน + LINE ลูกค้า

ผู้ใช้สั่ง 28 ก.ย. 69 ("ตามแนะนำ") หลังถามว่า "จะรู้ได้อย่างไรว่าสิทธิ์คงเหลือ 3 ครั้ง ไปดูตรงไหน"
สถานะ: **เสร็จ 28 ก.ย. 69**

## ปัญหา

- ทุกที่บอกแค่ "เหลือ 3 ครั้ง" — ลูกค้าโทรถาม "ล้างได้อีกเมื่อไร" ทีมต้องเปิดประวัติแล้วบวก 6 เดือนเอง
- เลข 4 ของสิทธิ์ตั้งต้นไม่บอกที่มา — คนดูเข้าใจผิดว่า 4 ครั้ง/ปี (จริง ๆ 2 ครั้ง/ปี × 2 ปี · ถามมาแล้ว 28 ก.ย.)

## ทำอะไร

1. `lib/om/entitlement.ts` เพิ่ม `NEXT_WASH_SQL` = ล้างล่าสุด + `cycle_months` — **สูตรเดียวกับ `DUE_WASH_SQL`**
   (วันที่โชว์กับวันที่บ้านเด้งเข้าแท็บติดตามต้องเป็นวันเดียวกัน) · ไม่เคยล้าง = NULL
2. **ทะเบียนบ้าน** (`/om/houses` modal กล่องสิทธิ์ล้างแผง)
   - บรรทัดใต้หัวข้อ: `ล้างทุก 6 เดือน · ครบรอบถัดไป 28 มี.ค. 2570` / `ถึงรอบล้างแล้ว` (+ `ยังไม่เคยล้าง`)
     · สิทธิ์หมดและถึงรอบ → ต่อท้าย `สิทธิ์หมด ต้องเสนอราคาก่อนนัด` (ตรงกับ gate ใน `/api/om/follow`)
   - แถวสิทธิ์ตั้งต้นที่มี `contract_term` → `สัญญา 2 ปี · 2 ครั้ง/ปี` (ไม่มีเทอม = ไม่เดา)
   - API `/api/om/houses/[id]`: บ้านคืน `next_wash` / `wash_due` · grants คืน `contract_term`
3. **LINE ลูกค้า** (`/om/liff` กล่องสิทธิ์ล้างแผงคงเหลือ) — เฉพาะตอนสิทธิ์ > 0
   `รอบล้างถัดไป 28 มี.ค. 70` / `ถึงรอบล้างแล้ว` · สิทธิ์หมดไม่โชว์ (กันลูกค้าเข้าใจว่าได้ล้างฟรี)
   - API `/api/om/liff/me`: house คืน `next_wash` / `wash_due`

## ไม่ทำ

- ไม่มี migration · ไม่แตะสูตรยอดสิทธิ์ · ไม่จำกัดจำนวนครั้งต่อปี (ยังเป็นคำถามค้างฝั่งธุรกิจ)
- ไม่กันการนัดก่อนครบรอบ (ตอนนี้นัดก่อนได้ — รอผู้ใช้เคาะว่าตั้งใจหรือไม่)

## ตรวจ (28 ก.ย. 69 บน solardb_v3)

- บ้าน 18214 (lead 661): `/api/om/houses/18214` → `next_wash 2027-03-28` · `wash_due 0` · grant `qty 4 term 2` ✓
- 18213 → 2027-03-22 · 16771 / 18215 (ไม่เคยล้าง) → NULL + ถึงรอบ ✓
- ความสอดคล้องทุกบ้าน O&M 1,828 หลัง: ถึงรอบ = ไม่เคยล้าง 770 + เลยวันครบรอบ 889 · ยังไม่ถึง = วันครบรอบในอนาคต 169 — **ไม่มีแถวขัดกัน**
- `npx tsc --noEmit` ผ่าน · `/om/houses` `/om/liff` ตอบ 200
- ยังไม่ได้ทดสอบ LIFF ด้วยบัญชี LINE จริง (ใช้สูตร SQL ก้อนเดียวกับที่ตรวจแล้ว)
