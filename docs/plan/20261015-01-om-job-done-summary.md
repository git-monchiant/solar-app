# สรุปใบตรวจรับงานหน้าเดียว เมื่อปิดงานแล้ว (ขั้น 05 เข้างาน)

ที่มา: ผู้ใช้ถาม 15 ต.ค. 69 "เมื่อปิดงานไปแล้วให้สรุปรายงานเป็นหน้าเดียวเหมือน step อื่นได้ไหม" → ตอบ "ทำตามแนะนำ"

สถานะ: **เสร็จ 15 ต.ค. 69**

## ปัญหา

ขั้น 05 ที่ปิดแล้ว กางออกมาเป็นใบตรวจตัวเต็ม (`JobFormPanel`) โหมดอ่านอย่างเดียว
ยังแบ่ง 3 แท็บย่อย (ตรวจ / รูป · บันทึก / ส่งมอบ) และเป็นช่องกรอกที่กดไม่ได้ทั้งหน้า ต้องสลับแท็บถึงจะเห็นครบ
ขั้นอื่น (ขั้น 01–04 ของ O&M · ขั้นติดตั้งฝั่งขาย) กางแล้วเป็นหน้าสรุปหน้าเดียว

## ทำ

แทนใบตรวจตัวเต็มด้วยหน้าสรุป (ผู้ใช้เลือกตามคำแนะนำ — ไม่เก็บลิงก์ใบตรวจเต็ม · รายละเอียดครบอยู่ในปุ่ม "ใบบริการ" PDF)
ยกผังจาก `renderDoneContent` ของ `InstallStep` ฝั่งขาย: กล่องวันที่ + `DoneSection` + แถว "หัวข้อ … ค่า"

1. กล่องวันที่ — วันนัด · ช่างเริ่มงาน (จากเหตุการณ์ start ใน Activity log) · วันปิดงาน
2. ใบบริการ — เลขที่ · ประเภทงาน · ทีมช่าง · ขนาดติดตั้ง · ใบตรวจ (ชื่อ · รุ่น) · ผลตรวจ
3. หมวดในใบตรวจ (คุณภาพงาน / การทดสอบระบบ / หมวดอื่น) — ข้อผ่าน/ไม่ผ่าน ✓ ✗ + หมายเหตุ · ข้อวัดค่า + หน่วย · ว่าง = "-"
   หัวข้อมาจากใบตรวจที่ผูกกับใบงาน (`form.items`) ไม่ hardcode — ใบเก่าที่ใช้ใบรุ่นอื่นยังอ่านถูก
4. สรุป · บันทึกเพิ่มเติม — ผ่าน/ไม่ผ่านกี่ข้อ · บันทึกของช่าง · พบงานซ่อม (เฉพาะใบที่มี)
5. รูปก่อน / หลังทำงาน — รูปย่อ กดดูขยายได้ (ไม่มีรูป = ไม่แสดงกล่อง แบบฝั่งขาย)
6. ลายเซ็น — ช่าง · ลูกค้า · ผู้ตรวจสอบ / Q.C. (ลายเซ็นอัตโนมัติ) · วิธีปิดงานเฉพาะใบเก่าที่ไม่ใช่ลูกค้าเซ็นที่หน้างาน

บรรทัดหัวการ์ด "ผลตรวจ ผ่าน · ใบบริการ OM-…" + ปุ่ม "ใบบริการ" คงเดิม

## ไฟล์

- ใหม่ `src/components/om/JobReportSummary.tsx`
- `src/components/om/JobDetail.tsx` — การ์ดขั้น 05 ที่ปิดแล้วใช้หน้าสรุปแทน `JobFormPanel`

## ไม่แตะ

- API — ใช้ GET `/api/om/jobs/[id]/report` ตัวเดิม (ข้อมูลชุดเดียวกับใบตรวจ/ใบบริการ PDF)
- หน้าช่าง `/om/field/[id]` และขั้น 05 ที่ยังไม่ปิด — ยังเป็นใบตรวจตัวเต็ม
