# หน้างานบริการ O&M: ตัวกรอง "ล้างแล้วกี่ครั้ง"

สถานะ: **done 24 ต.ค. 69**

## ที่มา

ผู้ใช้ถาม "ถ้าจะค้นหาจำนวนครั้งล้างแผงได้ไหม" — เสนอ A ช่องกรอง dropdown / B พิมพ์ในช่องค้นหา → ผู้ใช้ "ตามแนะนำ" (A)
ทำแบบ "ล้างไปแล้วกี่ครั้ง" ตามคำถาม (สิทธิ์คงเหลือยังเรียงได้จากช่องเรียง "สิทธิ์ล้างคงเหลือ")

## ทำ

- `/api/om/follow` รับ `wash` = 0 ยังไม่เคยล้าง · 1 · 2 · 3 (3 ครั้งขึ้นไป) — กรองจาก `wash_count` ของ `#due` (ใบตัดสิทธิ์ล้างแผงที่ไม่ยกเลิก) ซ้อนบนแท็บ/โครงการ/ที่มา/คำค้น
- คืน `wash_counts` = จำนวนบ้านต่อตัวเลือก ตามแท็บ/โครงการ/ที่มาที่เลือก (ไม่นับคำค้น แบบรายชื่อโครงการ)
  · recordset ใหม่อยู่ index 4 — history / bookings ของโหมดบ้านเดียวขยับเป็น 5 / 6
- หน้า `om/services`: dropdown "ทุกจำนวนครั้งที่ล้าง" ต่อจากช่อง "ทุกที่มา" — ยังไม่เคยล้าง · ล้างแล้ว 1 / 2 / 3 ครั้งขึ้นไป · เลขกำกับ

## ทดสอบ (อ่านอย่างเดียว)

- แท็บทั้งหมด: 0 = 749 · 1 = 214 · 2 = 179 · 3+ = 610 รวม 1,752 ตรงกับแท็บ · กรองแต่ละตัวได้บ้านที่ wash_count ตรง
- แท็บติดตาม: 436 + 180 + 175 + 172 = 963 · เลือก "ล้างแล้ว 2 ครั้ง" → "1–30 จาก 175 รายการ"
- โหมดบ้านเดียว (หน้ารายละเอียด) history / bookings ยังมาครบ
- tsc + eslint ผ่าน · หน้าจริง 1366 แถวตัวกรองไม่ล้น
