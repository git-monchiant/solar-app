# ใบเสนอราคา O&M — แท็บเงื่อนไข/ข้อกำหนด แก้ไข/เพิ่ม/ลด ได้แบบฝั่งขาย

ที่มา: ผู้ใช้ส่งภาพแท็บเงื่อนไขของ popup O&M (ยังอ่านอย่างเดียว) 2 ต.ค. 69 "ปรับให้เหมือนงานขายคับ การแก้ไขเพิ่มลด อะไรต่างๆ"
ต่อจาก [20261002-04](20261002-04-om-quote-editor-like-sales.md)

สถานะ: **เสร็จ 2 ต.ค. 69**

## ทำอะไร

- ใช้ `QuotationTermsEditor` ของฝั่งขายตัวเดียวกัน (แก้ถ้อยคำ · เพิ่ม/ลบ/เลื่อนหัวข้อและบรรทัด · คืนค่าจาก Master รายหัวข้อ/ทั้งหมด)
  - เติม prop เดียว `master` (ไม่ส่ง = ทำงานแบบเดิมทุกอย่าง) — ใบ O&M ส่งชุด Master ของ O&M แทนชุดมาตรฐานงานขาย
- ชุด Master ของ O&M (`lib/om/om-terms.ts` ใช้ได้ทั้งหน้าจอและ server): ขอบเขตงาน (Package O&M) · หมายเหตุ (หมายเหตุ Package O&M) · อายุใบ (`{{valid_days}}`)
  key ขึ้นต้น `om-` ไม่ชนชุดงานขาย (ตัวจัดหน้าของงานขายดูหน้าจาก key) ⇒ ทุกหัวข้ออยู่หน้า 1 แบบเดิม
- เก็บชุดที่แก้ใน `quotations.document_inputs_json.terms` ที่เดียวกับฝั่งขาย (ยังไม่แก้ = NULL → ใช้ชุด Master ตามแพ็กเกจ)
  ตรวจ/ล้างด้วย `parseQuotationTermTree` ตัวเดียวกับฝั่งขาย · Revision คัดลอกคอลัมน์นี้อยู่แล้ว
- PDF ใบจริง + ตัวอย่าง: ใช้ `renderQuotationTermTree` ตัวเดียวกับฝั่งขาย (ชุดที่แก้ หรือชุดจาก terms_text เดิม)
  ⇒ เลขข้อในใบ O&M เปลี่ยนเป็นแบบฝั่งขาย "1.1)" (เดิม "1.1") · ใบที่ส่งอนุมัติแล้วไม่เปลี่ยน (ข้อมูลเอกสารแช่ไว้)

## ไม่ทำ

- ไม่มี migration · ไม่แก้ชุด Master (แก้ที่หน้า Package O&M เหมือนเดิม)

## ตรวจ

- tsc · eslint · popup: แก้ถ้อยคำ/เพิ่มหัวข้อ/ลบบรรทัด → ดูตัวอย่าง → บันทึก → เปิดใหม่ยังอยู่ → PDF ใบจริงตรง · คืนค่าจาก Master ทั้งหมด → กลับชุดแพ็กเกจ
  · หน้าฝั่งขาย (lead 924) แท็บเงื่อนไขยังเหมือนเดิม · ลบข้อมูลทดสอบ

## บันทึกการทำ (2 ต.ค. 69)

- ทำครบตามหัวข้อ "ทำอะไร" · `omLegalContent` เดิมเอาออก (แทนด้วย `omLegal` ใน om-terms.ts) · แก้ QuotationTermsEditor ฝั่งขาย 3 จุด (prop master · ชุดตั้งต้น · ป้ายชุดไม่ตรง)
- ผลตรวจ: tsc / eslint ผ่าน · ไม่มี console error · ลองบนบ้าน 311/77 ผ่านหน้าจอจริงแล้วลบทิ้ง (ใบงาน #141)
  - แท็บเงื่อนไข: 3 หัวข้อจาก Package O&M · ปุ่ม "+ เพิ่มหัวข้อ" / "↺ คืนค่าจาก Master ทั้งหมด" (ปิดไว้จนกว่าจะแก้) / รายหัวข้อ "+ เพิ่มรายละเอียด" "↺ คืนค่าจาก Master หัวข้อนี้" / ↑↓× ครบแบบฝั่งขาย
  - เพิ่มหัวข้อ "การรับประกันงานบริการ" + ลบหมายเหตุข้อ 1 → บันทึกฉบับร่าง → อ่านกลับ 4 หัวข้อ · PDF ใบจริงขึ้นตามที่แก้ (1.1) … 4.1)) · เปิดใหม่ยังอยู่
  - คืนค่าจาก Master ทั้งหมด → บันทึก → terms = null (กลับใช้ชุดแพ็กเกจ)
  - ฝั่งขาย lead 924: แท็บเงื่อนไขยังเป็น 4 หัวข้อมาตรฐานงานขาย ไม่มี error
