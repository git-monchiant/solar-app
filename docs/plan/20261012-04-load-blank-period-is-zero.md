# Load Assumption: ช่วงเวลาที่เว้นว่าง = ไม่ได้ใช้ (ไม่ต้องกด − ให้เป็น 0)

วันที่: 12 ต.ค. 2569 · branch: `v3-ui-consistency` (ทำในเครื่อง)
ต่อจาก: [20261012-03-load-card-incomplete-warning.md](20261012-03-load-card-incomplete-warning.md)

## ที่มา

หลังเพิ่มคำเตือนการ์ดกรอกไม่ครบ ลีด #924 เครื่องทำน้ำอุ่นใส่ 1 เครื่อง กลางวัน 10 นาที กลางคืนเว้นว่าง
ก็ยังขึ้นเหลือง "ยังไม่ได้ใส่ กลางคืน (ช่วงที่ไม่ได้ใช้ กด − ให้เป็น 0)"
ผู้ใช้: "ไม่ต้องบังคับกด 0 ได้ไหม แค่ไม่กรอก ก็แค่ไม่มีข้อมูล ให้สมเหตุสมผลหน่อย"

## การตัดสินใจ

- **D1** อุปกรณ์แบบ จำนวน + ชั่วโมงกลางวัน/กลางคืน (น้ำอุ่น · ปั๊ม · ทีวี · หลอดไฟ · แอร์):
  กรอกชั่วโมงช่วงเดียวพอ — อีกช่วงที่เว้นว่างนับเป็น 0 · รายงาน §3 พิมพ์ "0 ชม." แทนช่องให้เขียนมือ
- **D2** ยังต้องมี: **จำนวน** (ไม่มีก็คำนวณไม่ได้) และ **ชั่วโมงอย่างน้อย 1 ช่วง** (ว่างทั้งสองช่วง = ยังไม่ได้ถาม)
- **D3** แอร์: นับเฉพาะชั่วโมงของช่วงที่มีเครื่อง — ชั่วโมงค้างจากช่วงที่ไม่มีเครื่องแล้วไม่ทำให้อีกช่วงเป็น 0
- **D4** เครื่องซักผ้า (ครั้ง/สัปดาห์ + ช่วง) และ EV (ครั้ง + ชม./ครั้ง + ช่วงชาร์จ) ยังต้องครบ — ทุกช่องเป็นตัวคูณ ไม่ใช่ช่วงเวลา
- **D5** ประตูส่งใบเสนอราคาเข้าอนุมัติใช้กติกาเดียวกัน (อ่านจาก `computeLoad`) — ช่วงที่เว้นว่างไม่บล็อกแล้ว
- **D6** แถบสรุปบอก "ช่วงที่เว้นว่าง = ไม่ได้ใช้" · ช่องชั่วโมงขึ้นสีส้มเฉพาะตอนว่างทั้งสองช่วง
