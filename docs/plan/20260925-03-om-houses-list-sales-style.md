## แนวทาง

- ยกโครงหน้าของ Pipeline / งานบริการ: `ListPageHeader` (ชื่อเมนู · ค้นหา · แท็บ+ตัวเลข) + แถวเครื่องมือ
  (จำนวน · `Dropdown` โครงการ) — ตามกติกา ui-rules ที่หน้า list ต้องใช้ ListPageHeader
- **desktop ยังเป็นตาราง** — หน้านี้คือทะเบียนสำหรับไล่ตรวจ/เติมข้อมูล (ไม่มีขั้นงาน) · การ์ดมีที่ของมันแล้วคือหน้างานบริการ
- ตัดแถบสรุปใต้แท็บ (ซ้ำกับตัวเลขบนแท็บ) · ปุ่ม "แก้ไข" ท้ายแถว → ลูกศร › (กดทั้งแถว)

## ข้อค้นพบระหว่างทำ mockup

- ปุ่ม "+ เพิ่มบ้าน" ไม่มี onClick — กดแล้วไม่มีอะไรเกิดขึ้น
- API สถานะ sync (`/api/om/rem/sync`, `/api/om/sweep` GET) อ่านได้เฉพาะ admin / solar_sup / sales_sup
  → role อื่นเห็นกล่อง sync เป็นค่าว่าง ("0 unit · รอบล่าสุด —") มาตลอด
- ทะเบียน REM บน solardb_v3 ดึงล่าสุด 9 ก.ย. (16 วัน) ทั้งที่ควรดึงทุก 6 ชม. — ยังไม่ได้ตรวจสาเหตุ
- "ถึงคิวล้าง" หน้านี้ 1,546 vs งานบริการแท็บติดตาม 919 — นิยามต่างกัน (หน้านี้นับทุกหลังที่ไม่เคยล้าง/เลยรอบ)

## เก็บตก: เตือนนัดเด้งกลับเป็น "ยังไม่อ่าน" ทุกรอบ (เจอตอนตรวจรีสตาร์ต · ผู้ใช้สั่ง "เริ่มเลย")

  และทุกครั้งที่ server บูต ขัดกับตั้งใจ "รันซ้ำวันเดียวกันไม่แจ้งซ้ำ"

  (ประเภทอื่น — มอบหมาย/ผลตรวจสลิป — ไม่ส่ง = พฤติกรรมเดิม) · คืนค่าตาม rowsAffected ให้ log "แจ้ง N" ตรงจริง
