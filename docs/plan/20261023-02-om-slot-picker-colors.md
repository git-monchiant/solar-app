# โทนสีปฏิทินนัดหมาย O&M (ช่องว่าง / ไม่ว่าง)

สถานะ: **done 23 ต.ค. 69** (ผู้ใช้: "ตามแนะนำ ทำเฉพาะงาน O&M ก่อน") · mockup: [docs/mockup/20261023-02-om-slot-picker-colors/](../mockup/20261023-02-om-slot-picker-colors/)

## ปัญหา (23 ต.ค. 69)

ผู้ใช้ขอ "design โทนสีให้เหมาะสม เช่น ว่างสีอะไร ไม่ว่างสีอะไร ตามมาตรฐานทั่วไป · ยังไม่ต้องแก้โค้ด"

ปฏิทินเลือกวันนัด O&M (`CalendarPicker` โหมด `overlap="shared"` — ขั้น 04 / Reschedule):
- ช่องที่ **ไม่ว่าง** เพราะทีมติดนัดบ้านในโครงการเดียวกัน เป็น **พื้นเขียว** (`bg-emerald-50`) — มาตรฐานทั่วไปเขียว = ว่าง จึงอ่านสลับกับช่องว่าง (ขาว)
- ไม่ว่าง (โครงการอื่น) · ปิดช่อง · เลยเวลา หน้าตาเหมือนกันหมด (เทา)
- วันนี้ (พื้นม่วงอ่อน + วง) คล้ายวันที่เลือก (ม่วงทึบ)
- ไม่มีคำอธิบายสี

## ข้อเสนอ — สีหนึ่งมีความหมายเดียว

| สี | ความหมาย |
|---|---|
| ขาว | ว่าง เลือกได้ |
| ม่วง (สี active) | ที่เลือกอยู่ |
| เขียว | ข่าวดี/แนะนำ — ตัวนับว่าง · วันที่ทีมเข้าโครงการเดียวกัน · ชิปแนะนำ |
| เทา | ใช้ไม่ได้ — ไม่ว่าง · ปิด · เต็ม · เลยเวลา |
| แดง | เลขวันเสาร์–อาทิตย์เท่านั้น |

เปลี่ยน:
1. ช่องไม่ว่างโครงการเดียวกัน → พื้นเทาแบบไม่ว่าง + แถบเขียวซ้าย + บ้านเลขที่สีเขียว
2. ช่องไม่ว่างโครงการอื่น → บ้านเลขที่สีเทา (แทนจุดสีทีม)
3. ปิดช่อง → ลายทแยงเทา · เลยเวลา → จางกว่าไม่ว่าง
4. วันนี้ → วงเส้นม่วงอย่างเดียว ไม่มีพื้น · วันทีมติดนัดครบ → ขีดฆ่าเลข
5. แถบคำอธิบายสีใต้ช่องเวลา (เฉพาะ O&M)

คงเดิม: ช่องว่าง · ช่องที่เลือก · จุดส้มงานติดตั้ง · วงเขียววันทีมเข้าโครงการ · ตัวนับว่าง · ปฏิทินฝั่งขาย (โหมด block)

## ผลที่ทำ

- `src/components/calendar/CalendarPicker.tsx` เท่านั้น ทุกจุดอยู่ใต้โหมด `overlap="shared"` (O&M)
  - ช่องไม่ว่างโครงการเดียวกัน: `bg-gray-100 border-gray-200 text-gray-400 shadow-[inset_3px_0_0_#10b981]` + บ้านเลขที่เขียว
  - ช่องไม่ว่างโครงการอื่น: บ้านเลขที่สีเทา (เลิกจุดสีทีมของนัด O&M/สำรวจ · จุดส้มติดตั้งคงไว้)

  - แถบคำอธิบายสีใต้ช่องเวลา (ว่าง · เลือกอยู่ · ไม่ว่าง · ทีมอยู่โครงการนี้ [มีรหัสโครงการ] · ปิดช่อง · มีงานติดตั้ง)
