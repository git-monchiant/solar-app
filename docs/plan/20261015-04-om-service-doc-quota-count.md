# ใบบริการ O&M แสดง "ครั้งที่ · คงเหลือ" ของสิทธิ์ล้างแผง

ที่มา: ผู้ใช้ถาม 15 ต.ค. 69 (แนบรูปใบ OM-6909-0112) "ถ้าเพิ่มจำนวนครั้งที่ล้างไปแล้ว หรือคงเหลือ ในเอกสารนี้ มีแนวคิดอย่างไร"
→ เคาะ "1. ก. ครั้งที่ 3 · คงเหลือ 1 ครั้ง ส่วนข้ออื่นตามแนะนำ"

สถานะ: **เสร็จ 15 ต.ค. 69**

## หลักคิด

- ใบ PDF สร้างใหม่ทุกครั้งที่เปิด — ถ้าดึงยอดคงเหลือ "วันนี้" ใบเก่าจะเปลี่ยนเลขตามการล้าง/ซื้อเพิ่มครั้งหลัง ๆ
  ⇒ **จดตัวเลขไว้ตอนปิดงาน** ลงแถวตัดสิทธิ์ของงานนั้น (`om_redemptions`) แล้วใบอ่านจากแถวนั้น
  (หลักเดียวกับล็อกผู้ตรวจ Q.C. ไว้ที่ `om_job_report.qc_user_id`)
- ย้อนสถานะงาน → แถวตัดสิทธิ์เป็น void ตัวเลขหายไปเอง · ปิดใหม่ได้แถวใหม่พร้อมตัวเลขใหม่ — ไม่ต้องมีโค้ดดูแลเพิ่ม

## ทำ

- migration `20261015-1700_om_redemption_doc_snapshot.sql`: เพิ่ม `om_redemptions.seq_no` (ครั้งที่) · `balance_after` (คงเหลือหลังตัด · ติดลบได้)
  - เติมย้อนหลังให้แถวที่ผูกใบงาน (ปิดงานไปแล้ว) โดยไล่สมุดสิทธิ์ของบ้าน: ครั้งที่ = แถว used ของบ้าน+ชนิดงานเดียวกันที่ id ≤ แถวนี้
    · คงเหลือ = สิทธิ์ที่เติมก่อนเวลาแถวนี้ − ครั้งที่
- ปิดงาน (`PATCH /api/om/bookings/[id]`): คิวรียอดก่อนตัดเดิมดึง total_used เพิ่ม → INSERT พร้อม seq_no = ใช้ไป + 1 · balance_after = คงเหลือ − 1
- `loadJobReport` อ่าน seq_no / balance_after ของแถวตัดสิทธิ์ที่ยังไม่ void ของใบงาน
- ใบบริการ: ช่อง CUSTOMER INFORMATION ขวาของ "วันนัด" (ว่างอยู่) → `สิทธิ์ล้างแผง  ครั้งที่ 3 · คงเหลือ 1 ครั้ง`
  ไฟล์รวมของแท็บปิดงานใช้ตัวสร้างเดียวกัน ได้ตามไปเอง

## กติกา (ผู้ใช้เคาะ "ตามแนะนำ")

- แสดงเฉพาะงานที่ตัดสิทธิ์ (consumes_quota = 1 · ล้างแผง) — งานซ่อมไม่แสดง
- ฉบับร่าง (ยังไม่ปิดงาน) ไม่แสดง — ยังไม่ได้ตัดสิทธิ์
- ยอดติดลบ (ล้างเกินสิทธิ์) ในใบแสดง "คงเหลือ 0 ครั้ง" — ในฐานเก็บค่าจริง
- ลูกค้าซื้อทีละครั้ง แสดงเหมือนบ้านอื่น ("คงเหลือ 0 ครั้ง") — รอบแรกไม่ได้เสนอทางเลือกข้อนี้ เลือกแบบตรงที่สุดไว้ก่อน
- ไม่มีตัวหาร "จาก N ครั้ง" — สิทธิ์ของบ้านซ้อนหลายก้อน (โปรฯ + ซื้อ − หมดอายุ)
- "ครั้งที่" นับเฉพาะการล้างที่บันทึกในระบบ (ประวัติ REM ก่อนเข้าระบบไม่มีแถวตัดสิทธิ์)
