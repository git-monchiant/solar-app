## 1. คัดลอก BOQ

ปัญหา: กดสร้างได้แค่ใบเปล่า (Rev 0) — โครงการหลายขนาด (เช่น BGAC 4 ขนาด) ต้องเลือกวัสดุใหม่ทุกใบ

- ป๊อปอัป "+ BOQ ขนาดใหม่" (หน้าโครงการ) และ "+ สร้าง BOQ" (หน้ารายการ) เพิ่มช่อง **"เริ่มจาก"**:
  ใบเปล่า / คัดลอกจาก BOQ ใบอื่น (Rev ล่าสุดของทุกเลขที่ · ใบของโครงการเดียวกันขึ้นก่อน)
- `POST /api/b2b/boqs` รับ `copy_from` (id ใบต้นทาง Rev ไหนก็ได้) → ใบใหม่ เลขที่ใหม่ Rev 0 ในโครงการที่เลือก
- **คัดลอก**: บรรทัดทั้งหมด (ลำดับ · จำนวน · หมายเหตุ) · ส่วนเพิ่มเติม รวม/ทางเลือก · VAT ·
  Margin ตั้งค่าเริ่มต้นตามใบต้นทาง (แก้ได้ในป๊อปอัป)
- **ราคา**: ใบใหม่ใช้ **ราคาปัจจุบันใน Master** (กติกาเดียวกับ "บรรทัดใหม่ดึงจาก Master ตอนนี้" ของ API บันทึก)
  - รายการที่ปิดใช้งานใน Master แล้ว: คงข้อมูล/ราคาเดิม ขึ้นป้าย "ปิดใช้งานใน Master" (มีอยู่แล้วในหน้าทำ BOQ) · แจ้งจำนวนหลังสร้าง
  - ราคาใส่เอง (หมวดเสริม 19–25): คัดลอกตามเดิม
- **ไม่คัดลอก**: ชื่อตัวเลือก (กรอกใหม่) · หมายเหตุหัวใบ · ชื่อโครงการ/ลูกค้า/ที่ตั้ง (มาจากโครงการปลายทาง)
- timeline โครงการ: "เพิ่ม BOQ X · ตัวเลือก (คัดลอกจาก Y Rev n)"

## 2. หมายเหตุรายบรรทัด

ปัญหา: ตาราง `b2b_boq_items.note` มีอยู่แล้ว (API บันทึก/ออก Rev ส่งต่อครบ) แต่หน้าจอไม่มีช่องกรอก

- หน้าทำ BOQ: ใต้ชื่อรายการมีปุ่ม "+ หมายเหตุ" → ช่องพิมพ์ (สูงสุด 500 ตัวอักษร) · มีแล้วแสดงช่องให้แก้ต่อ · อ่านอย่างเดียวแสดงข้อความ
- Excel: ใส่เป็น comment ของช่องชื่อรายการ (ไม่ขยับผังที่ตรวจกับไฟล์จริงแล้ว 227 ช่อง)

## 3. ซ่อนต้นทุน/Margin จากบัญชี

ปัญหา: บัญชีเปิดหน้าโครงการได้ (ยืนยันงวดเงิน) และเห็นต้นทุน/Margin ในตาราง BOQ + ลิงก์ BOQ ที่เปิดแล้วไม่มีสิทธิ์

- `GET /api/b2b/projects/[id]`: role ที่ไม่มีสิทธิ์ดู BOQ (`B2B_BOQ_VIEW_ROLES`) → `total_cost` / `margin_pct` เป็น null (ตัดที่ server ไม่ใช่แค่ซ่อนบนจอ)
- หน้าโครงการ: ตาราง BOQ ไม่มีคอลัมน์ต้นทุน/Margin และชื่อตัวเลือกไม่เป็นลิงก์ · หัวหน้าไม่มีตัวเลข Margin · การ์ดขั้นต่อไปไม่มีลิงก์ "เปิด BOQ"

## 4. จำกัดตัวเลข

ปัญหา: ไม่จำกัดจำนวน/ราคาสูงสุด — พิมพ์เลขใหญ่เกินช่อง DECIMAL ได้ error 500

- จำนวนต่อบรรทัดไม่เกิน 1,000,000 · ราคาใส่เองไม่เกิน 100,000,000 บาท/หน่วย
- ยอดรวมทั้งใบ (ต้นทุน/ขาย) ไม่เกิน 1 ล้านล้านบาท — เกินแจ้งข้อความ (400) แทน 500
- ข้อความผิดพลาดบอก **"หมวด X ลำดับ N"** ตรงกับเลขบนจอ (แก้ข้อ ⚪ "บรรทัดที่ N ไม่ตรงเลขบนจอ" ของแผน 12 ไปด้วย)
