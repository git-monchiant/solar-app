# หน้างานบริการ O&M: แท็บ "ทั้งหมด" + ค้นหาทุกแท็บ + แบ่งหน้า

สถานะ: **done 23 ต.ค. 69**

## ที่มา

ผู้ใช้ถาม "ถ้าอยากดูรายการทั้งหมด 1,752 รายการ ไปดูที่ไหน" — พบว่า
- "1,752 รายการ" เป็นตัวเลขผลรวม กดไม่ได้
- หน้าโหลดแค่ 40 ใบแรกของแท็บ ไม่มีทางดูต่อ (แท็บติดตาม 963 ใบ เห็น 40)
- ช่องค้นหาค้นเฉพาะแท็บที่เปิด — หาบ้านที่อยู่แท็บอื่นไม่เจอ

ผู้ใช้เคาะ "ทำครับ" (ข้อเสนอ 1 แท็บทั้งหมด + 2 ค้นทุกแท็บ) · แบ่งหน้าทำด้วยเพราะไม่งั้นแท็บทั้งหมดก็เห็นแค่หน้าแรก

## ทำ

- `/api/om/follow`: `tab=all` = ทุกแท็บ (รายการ · จำนวน · รายชื่อโครงการ)
- `om/services/page.tsx`
  - แท็บแรก **ทั้งหมด (n)** แทนตัวเลข "x รายการ" (แบบแท็บทั้งหมดของ Pipeline ฝั่งขาย) · การ์ดบอกแท็บของตัวเองด้วยป้ายมุมขวาอยู่แล้ว
  - พิมพ์ค้นหา = ค้นทุกแท็บ แถบแท็บชี้ "ทั้งหมด" · ล้างคำค้นกลับแท็บเดิม · กดแท็บอื่น = ล้างคำค้น · ไม่พบ = "ไม่พบรายการที่ค้นหา"
  - แถบแบ่งหน้ายกจากหน้าบ้าน / ระบบติดตั้ง O&M: "1–30 จาก n รายการ · หน้า x จาก y · 30/50/100 ต่อหน้า · ‹ 1 2 … ›" (เดิม 40 ใบแรก)
  - เปลี่ยนแท็บ/ตัวกรอง/เรียง/คำค้น/จำนวนต่อหน้า = กลับหน้า 1 · เปลี่ยนหน้าเลื่อนขึ้นบนสุด
