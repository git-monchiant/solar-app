# Timeline โฟกัส Milestone + SLA

วันที่: 2026-08-20
สถานะ: cancelled

> ทำเสร็จและตรวจผ่านแล้ว แต่ผู้ใช้เลือกกลับไปใช้ Timeline แบบเดิม จึง revert โค้ดออกทั้งหมด
> เอกสารนี้เก็บไว้เป็นบันทึกว่าเคยลองอะไร และติดข้อจำกัดอะไร เผื่อรื้อฟื้นภายหลัง

## เป้าหมาย

Timeline ควรตอบว่า **"ถึงไหนแล้ว และทันเวลาไหม"** ส่วน Activity Log ตอบว่า
**"ใครทำอะไรเมื่อไหร่"** เดิม Timeline ทำสองอย่างซ้อนกัน ทำให้บางขั้นมีแถวจำนวนมาก
เพื่อบอกเรื่องเดียว

## กติกาการแสดงผลใหม่

| ประเภทแถว | ผล |
| --- | --- |
| Milestone (ลงทะเบียน, ออกใบจอง, ชำระเงิน, นัดสำรวจ, สำรวจเสร็จ, ส่งใบเสนอราคา, ติดตั้งเสร็จ, ใบรับประกัน) | แสดงเสมอ |
| แถว SLA | แสดงเสมอ |
| เหตุการณ์ผิดปกติ: ยกเลิก/เลื่อนนัด และ rollback ย้อนขั้น | แสดงเสมอ |
| `status_change` ปกติ ("เข้าสู่ขั้น X") | ซ่อน — แถว SLA ของขั้นนั้นบอกอยู่แล้ว |
| กิจกรรมติดต่อ (call, visit, line, follow_up) และ note | ซ่อน — สรุปอยู่ในแถว SLA FIRST_CONTACT / CONTACT_RETRY / GRADE_PLAYBOOK |
| "โดย &lt;ชื่อ&gt;" | ตัดออกจากแถวที่แสดงเสมอ เหลือเฉพาะแถวรายละเอียดที่กางเอง |

Rollback ยังแสดงเสมอทั้งที่เป็น `status_change` เพราะเป็นคำอธิบายว่าทำไม SLA
ถึงออกมาแบบนั้น ถ้าตัดไป Timeline จะเล่าเรื่องราบรื่นเกินจริง

## ปุ่ม "แสดงรายละเอียดทั้งหมด"

แต่ละขั้นมีปุ่มของตัวเอง กดแล้วแถวที่ซ่อนไว้จะกลับมา **เรียงตามเวลาเดิม**
ไม่ใช่ไปกองท้ายขั้น

จำเป็นต้องมีเพราะ **Activity Log เข้าถึงไม่ได้บนมือถือ** — panel เป็น `hidden md:flex`
และปุ่ม tab ถูกถอดออกไปแล้ว ถ้าซ่อนเฉย ๆ ผู้ใช้มือถือจะไม่เหลือทางเห็นรายละเอียดเลย

ขั้นที่มีแต่แถวรายละเอียดล้วนจะกางไว้ตั้งแต่แรก เพื่อไม่ให้เห็นขั้นว่างเปล่า
ส่วนตัวเลข x/y ที่หัวขั้นนับเฉพาะแถวที่แสดงตามปกติ จึงไม่กระโดดตอนกดกาง

## สิ่งที่แก้

`src/app/(app)/leads/[id]/page.tsx` เท่านั้น

- `Bullet` เพิ่มฟิลด์ `detail`
- เพิ่ม `isDetailActivity()` และให้ `activityRows()` ติดธงพร้อมตัด "โดย" ออกจาก
  แถวที่ไม่ใช่รายละเอียด
- state `openTimelineDetail` + `toggleTimelineDetail` แยกต่อขั้น
- แยก `shownItems` ออกจาก `timelineItems` และเพิ่มปุ่มท้ายแต่ละขั้น

## ข้อจำกัดที่ยังเหลือ

ขั้นที่มีการนัดหมายหลายรอบจะยังเห็นหลายแถว เช่น "นัดติดตั้ง → ยกเลิกนัด →
นัดติดตั้งใหม่ → ยืนยันนัด" เพราะทั้งหมดเป็นเหตุการณ์จริงคนละครั้ง ไม่ใช่แถวซ้ำ
เช่นเดียวกับ "ปิดงานติดตั้งเรียบร้อย" ที่ขึ้นสองครั้งเพราะถูก rollback แล้วปิดใหม่จริง
ถ้าต้องการยุบให้เหลือเฉพาะนัดล่าสุด ต้องเพิ่มกติกาแยกอีกชั้น
