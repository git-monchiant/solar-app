# Survey Layout Sketch Upload

Status: done

## Goal

เพิ่มรูปผังร่างจุดติดตั้งอุปกรณ์เป็นไฟล์เฉพาะของงานสำรวจ ให้ทีมสำรวจถ่ายรูปหรือเลือกไฟล์จากเครื่องได้ด้วยรูปแบบเดียวกับรูปตามรายการ และนำไฟล์เดียวกันไปแสดงในแท็บ Photos และหน้า Equipment Layout Sketch ของรายงาน PDF

## Scope

- เพิ่มฟิลด์เก็บ URL รูปผังร่างใน `leads`
- รองรับอ่าน/แก้ไขฟิลด์ผ่าน Lead API และชนิดข้อมูลฝั่ง UI
- เพิ่มการ์ดอัปโหลดหนึ่งรูปใน Survey > เตรียม พร้อมถ่ายรูป เลือกไฟล์ ดู เปลี่ยน และลบ
- แสดงและให้อัปโหลด/เปลี่ยนรูปใน Photos > Survey แยกจากรูปสำรวจอื่น เพื่อรองรับงานที่ปิด Survey แล้ว
- แสดงรูปเต็มกรอบในหน้า 5 ของรายงานสำรวจ หากไม่มีรูปให้คงพื้นที่ว่างเดิม
- ไม่เพิ่มเครื่องมือวาดรูปในโปรแกรม และยังไม่บังคับแนบรูปเพื่อปิดงานสำรวจ

## Verification

- ตรวจ migration และ PATCH field
- ตรวจ TypeScript/ESLint
- สร้าง PDF ทดสอบและยืนยันว่ารูปอยู่หน้า Equipment Layout Sketch โดยไม่เปลี่ยนจำนวนหน้ารายงาน

## Progress

- UI, API, type, Photos และ PDF renderer ดำเนินการแล้ว
- ESLint ไม่มี error, TypeScript และ Next.js production build ผ่าน
- ทดสอบ PDF จริงมีรูปหน้า 5 และยังคง 15 หน้า; กรณีไม่มีรูปยังแสดงพื้นที่ว่างเดิม
- Apply `sql/133_survey_layout_sketch.sql` ไปยังฐานข้อมูล Development แล้ว และตรวจ schema/Lead query ผ่านโดยไม่แก้ข้อมูลลูกค้า
