# หน้าต่างรายละเอียดบ้าน O&M — จัดใหม่ให้ดูง่าย ไม่สูง

ผู้ใช้สั่ง 25 ก.ย. 69 (ดูจากภาพบ้าน 10): "จัดข้อมูลให้ดูง่าย ครบถ้วน การจัดเรียงให้ดูง่ายกว่านี้ ขนาดไม่สูงเกินไป"

## ปัญหา

modal (`/om/houses` → กดบ้าน) เรียงทุกอย่างเป็นคอลัมน์เดียวยาวลงมา: ฟอร์มบ้าน → ปุ่มซ่อน → ปุ่มลบ →
ระบบติดตั้ง → สิทธิ์ → ลูกค้า — ต้องเลื่อนยาวกว่าจะเห็นลูกค้า · การ์ดระบบตัวเล็ก (text-xxs) อ่านยาก

## ที่ทำ (ไฟล์เดียว `src/app/(app)/om/houses/page.tsx` · ไม่แตะ API/ข้อมูล)

- modal กว้างขึ้น `xl` → `2xl` · desktop แบ่ง 2 คอลัมน์ (mobile เรียงต่อกันเหมือนเดิม)
  - ซ้าย: **ข้อมูลบ้าน** (ฟอร์ม 2 ช่องต่อแถว · VIP/มีโซลาร์อยู่แถวเดียว) + **ลูกค้า** (มีข้อความเมื่อยังไม่ผูก)
  - ขวา: **ระบบติดตั้ง** + **สิทธิ์ล้างแผง** + **นัดล่าสุด**
- ปุ่ม "ซ่อนจาก O&M" / "ลบถาวร" ย้ายไป footer ซ้าย แบบเดียวกับ modal ลูกค้า (mobile ขึ้นแถวบน)
  ถ้าบ้านถูกซ่อนอยู่ → แถบเหลืองพร้อมปุ่มคืนอยู่บนสุดของ modal
- การ์ดระบบติดตั้ง: ตัวอักษร xxs → xs · ป้ายกว้างเท่าที่ใช้ ค่าชิดขวา ·
  วันเริ่ม + วันสิ้นสุดประกันรวมเป็นแถว "ช่วงประกันติดตั้ง" (บ้านจากงานขาย — แผน 20260925-01) ·
  แถวที่มาข้อมูลย่อเหลือบรรทัดเดียวพร้อมปุ่ม "ดูรายละเอียด"
- ชิปสิทธิ์ชนิดอื่นย้ายมาอยู่แถวเดียวกับปุ่ม บันทึกล้างแผง / ปรับสิทธิ์
- ชิป VIP บนหัว modal · `Sec` เพิ่ม `flush` (หัวข้อบนสุดของคอลัมน์ไม่มีเส้นบนซ้ำ)

### รอบ 2 (ผู้ใช้สั่ง "ให้แสดงรายละเอียดเลย" — ชี้ปุ่ม ดูรายละเอียด)

- ที่มาข้อมูลรายช่องแสดงในการ์ดระบบติดตั้งเลย — ยกแบบการ์ด mobile ของกล่องเดิม (ช่อง · ค่า · ป้ายที่มา / จุดอ้างอิง · วิธี · เมื่อ)
  แยกตามระบบ (`sourceRows()`) · ค่าที่ถูกเขียนทับโชว์ "เดิม → ใหม่" · เพิ่มแถวระเบียนจากระบบขาย (lead · ใบรับประกัน · วันที่สร้าง)
- ลบกล่อง "ที่มาข้อมูล" แยก + state `srcOpen` (ไม่มีทางเปิดแล้ว) · API รายละเอียดบ้านส่ง `created_at` ของระบบติดตั้งเพิ่ม
