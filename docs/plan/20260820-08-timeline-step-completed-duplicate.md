# ตัดแถวซ้ำ "ปิดงาน" ใน Timeline

วันที่: 2026-08-20
สถานะ: done

## ปัญหา

ขั้น Install ของ lead 691 แสดง "ปิดงานติดตั้งเรียบร้อย" สองแถว และขั้น
Warranty แสดง "ติดตั้งเสร็จและเข้าสู่การรับประกัน" สองแถวที่เวลาเดียวกันเป๊ะ

ตรวจข้อมูลจริงแล้วพบว่าการปิดงานหนึ่งครั้งเขียน activity **2 ใบในวินาทีเดียวกัน**

```
#3549  11 ก.ค. 10:03:30  step_completed  "ปิดงานติดตั้งเรียบร้อย"           → ขั้น Install
#3550  11 ก.ค. 10:03:30  status_change   install→warranty                  → ขั้น Warranty
```

เพราะการกดปิดงานหนึ่งครั้งทั้งบันทึกวันที่เสร็จ (`install_completed_at`) และ
เปลี่ยนสถานะพร้อมกัน API จึง log แยกสองใบ แล้ว Timeline จัดสองใบนี้ไปคนละขั้น
กลายเป็นเหตุการณ์เดียวถูกเล่าสองรอบ

ส่วนที่ขึ้นสองครั้ง (10:03 และ 13:17) ไม่ใช่ข้อมูลซ้ำ — เป็นการปิดงานจริงสองครั้ง
เพราะมีการย้อนสถานะกลับคั่นกลางเมื่อ 10:39

## สิ่งที่แก้

`src/app/(app)/leads/[id]/page.tsx` — `isCentralTimelineActivity()` ตัด
`step_completed` ที่มี `status_change` ของ lead เดียวกันอยู่ในวินาทีเดียวกัน

เลือกตัด `step_completed` เพราะขั้นนั้นยังได้แถว milestone จาก column ของ lead
(`ติดตั้งเสร็จสิ้น`) และแถว SLA ของขั้นก็บอกเวลาเสร็จกับผู้รับผิดชอบอยู่แล้ว
ส่วน `status_change` เป็นตัวบอกการข้ามขั้นซึ่งขั้นถัดไปต้องใช้

`step_completed` ที่ไม่มีคู่ (เช่น ปิด step โดยไม่เปลี่ยนสถานะ ในเคสเช็ค) ยังแสดงตามเดิม

| Warranty | ติดตั้งเสร็จและเข้าสู่การรับประกัน 10:03 + 13:17 | เท่าเดิม — เป็นการข้ามขั้นจริงสองครั้ง |

แถวในกรอบที่ผู้ใช้ชี้ 8 แถว เหลือ 7 แถว และไม่มีเหตุการณ์เดียวขึ้นสองขั้นอีก

## เรื่องที่ตรวจแล้วไม่ต้องแก้

แถว "ย้อนกลับไปขั้น Install · Manual rollback via admin" มี `created_by = null`
ตอนแรกวางแผนจะใส่ผู้ทำให้ แต่ค้นทั้ง repo แล้ว **ไม่มีโค้ดไหนสร้าง activity ข้อความนี้**
(`Manual rollback via admin` และ `Reverted to install step` ไม่ปรากฏในไฟล์ใดเลย)
เป็นการแก้ฐานข้อมูลด้วยสคริปต์ตอนทดสอบ ไม่ใช่ฟีเจอร์ในระบบ จึงไม่มีอะไรให้แก้
ถ้าต้องการปุ่มย้อนขั้นในระบบพร้อมบันทึกผู้ทำ ต้องทำเป็นฟีเจอร์ใหม่
