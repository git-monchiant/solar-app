# งานบริการ O&M — dropdown โครงการครบทุกแท็บ + "ลูกค้าทั่วไป" + กันเบอร์ปลอม

ที่มา: ผู้ใช้ถาม 15 ต.ค. 69 "โครงการแสดงครบยัง" (ชี้ dropdown "ทุกโครงการ (52)" หน้า `/om/services`) → ตอบว่าไม่ครบ เสนอแก้ → ผู้ใช้ "ตามคำแนะนำ"
ระหว่างทำผู้ใช้สั่งเพิ่ม "เปลี่ยนคำเป็น ลูกค้าทั่วไป" (ชี้ชิป "สิทธิ์หมด" บนการ์ดบ้านที่เพิ่มเอง) · ต่อจากแผน 20261014-08

สถานะ: **เสร็จ 15 ต.ค. 69** (ตรวจบน solardb_v3 · ไม่มี migration)

## ก่อนแก้ (ข้อมูลจริง solardb_v3)

- รายชื่อโครงการนับจาก **แท็บติดตามเสมอ** ไม่ว่าเปิดแท็บไหน (`/api/om/follow` · `WHERE d.bucket = 'follow'`)
  → ขึ้น 52 จาก 98 โครงการที่มีบ้านในงานบริการ · เช่น วิลล่า รามอินทรา (F9/2) 22 หลัง อยู่แท็บอื่นหมด กรองไม่ได้ · อีก 45 ส่วนใหญ่อยู่แท็บติดต่อไม่ได้
- บ้านไม่มีรหัสโครงการ (32 หลัง) รวมเป็นแถวเดียวที่ได้ชื่อบ้านหลังหนึ่งไปเป็นป้าย — **"บ้านอาจารย์บุญสม · 17"** กดกรองไม่ได้ (ค่าเป็น null)
- เลขข้างชื่อนับแท็บติดตาม ไม่ตรงกับที่เห็นในแท็บอื่น (ผิดกติกา ui-rules)

## แก้

- `src/app/api/om/follow/route.ts`
  - รายชื่อโครงการนับจาก **แท็บที่เปิด + งานของฉัน + ที่มา** — ชุดเดียวกับเลขบนแท็บ (ไม่นับคำค้น เหมือนเลขบนแท็บ)
  - บ้านไม่มีรหัสโครงการ = ตัวเลือก **"ลูกค้าทั่วไป · นอกโครงการ"** (`__NOPJ__` · คีย์/ป้ายชุดเดียวกับหน้าบ้าน `house-scope.ts`) **อยู่บนสุดต่อจาก "ทุกโครงการ"** (ผู้ใช้สั่ง) กรองได้จริง
- `src/app/(app)/om/services/page.tsx` — เลือกโครงการไว้แล้วสลับไปแท็บที่ไม่มีบ้านของโครงการนั้น คงชื่อไว้ "· 0" · "ทุกโครงการ (n)" นับเฉพาะที่มีบ้าน
- **ชิป "ลูกค้าทั่วไป"** (`JobCard.tsx` · ผู้ใช้สั่ง): บ้านที่ทีมเพิ่มเองที่ยังไม่เคยมีสิทธิ์ล้าง (`new_manual` จาก `follow-sql.ts`) ขึ้น "ลูกค้าทั่วไป" แทน "สิทธิ์หมด" · ซื้อแพ็กเกจแล้วใช้หมด = "สิทธิ์หมด" ตามปกติ
  ยังต้องเสนอราคาก่อนนัดเหมือนเดิม (กติกาดู balance ไม่ใช่ป้าย)
- **กันเบอร์ปลอม**: `isPlaceholderPhone()` ใน `src/lib/utils/formatters.ts` (0 + เลขเดียวซ้ำ 9 ตัว เช่น 0000000000 · 0999999999 · และ 0123456789)
  ฟอร์มเพิ่มบ้านขึ้นเตือน + บันทึกไม่ได้ · API ตอบ 400 · เช็คซ้ำไม่เอาเบอร์ปลอมมาเทียบ (ไม่งั้นคนที่ไม่เกี่ยวกันถูกบังคับผูกเป็นคนเดียว — เจอจากบ้านทดสอบ "เทส1" ที่ใช้ 0000000000)
  ★ ไม่ย้อนแก้ข้อมูลเดิม (เทส1 ยังมีเบอร์ 0000000000) · ไม่แตะฟอร์มอื่นนอก O&M
