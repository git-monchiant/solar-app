### 1. เลือกวันนัด / นัดโทรใหม่

ปัญหา: ช่อง `datetime-local` ต้องพิมพ์ · ไม่เห็นว่าช่วงไหนคิวเต็ม · ใส่เวลานอกช่วงทำการได้ (เช่น 14:37)
· รูปแบบเปลี่ยนตามภาษาเครื่อง (วว/ดด/ปปปป vs mm/dd/yyyy) · ขณะที่ปุ่ม Reschedule มีตัวเลือกช่วงเวลา+คิวอยู่แล้ว

- แยกส่วน "วัน + ช่วงเวลา" ออกจาก `OmRescheduler` เป็น `components/om/OmSlotPicker.tsx` (ย้าย ไม่ก๊อป) ใช้ 3 ที่
  - ขั้น 01 ผล "ตกลงนัด" · การ์ดนัดหมายตอนชำระเงินแล้ว (`callForm(true)`) · Reschedule
- วัน = `DateSlider` ตัวกลาง (ตัวเดียวกับ modal Follow-up ฝั่งขาย) แทน `<input type="date">`
  - ช่วงวัน = วันนี้ ถึง +`booking.advance_days_max` (ตอนนี้ 60) จากหน้าตั้งค่า
  - นัดใกล้กว่า `booking.advance_hours_min` (ตอนนี้ 24 ชม.) = **เตือนเหลือง ไม่บล็อก** (แนวเดียวกับช่องเต็ม/เลื่อนเกินเพดาน)
- ช่วงเวลา = `om_slot_config` ของวันนั้น + "คิวที่ใช้/ความจุ" (API `/api/om/bookings?from=&to=` ชุดเดิม)
  - ช่องเต็มยังกดได้แต่ตัวเลขแดง · ช่วงที่เริ่มไปแล้วของวันนี้กดไม่ได้ · วันปิดทำการบอกให้เลือกวันอื่น (กติกาเดิมของ OmRescheduler)
- เลือกครบแล้วขึ้นแถบ "นัดเป็น <วันไทย> <เวลา>" แบบแถบ "เลื่อนเป็น"
- ส่ง `scheduled_at = YYYY-MM-DDTHH:mm` (เวลาเริ่มของช่วง) — **API ไม่ต้องแก้**
  - ⚠ `DateSlider` เลือก "วันนี้" ให้เองถ้าไม่มีค่า ⇒ ต้องส่งค่าเริ่มให้เสมอ — ตกลงนัดเริ่มที่ **พรุ่งนี้** (ตาม advance_hours_min)
- นัดโทรใหม่ (ขอเลื่อน / ไม่รับสาย) = `DateSlider` เดียวกัน ไม่มีช่วงเวลา
  - **เลือกวันที่ระบบจะตั้งให้ไว้ก่อน** (วันนี้ + `call.postpone_days` 30 / `call.retry_days` 3) แก้ได้
    ใต้แถบบอก "ค่าเริ่มต้น +30 วันตามหน้าตั้งค่า" — เดิมช่องว่าง = ระบบตั้งให้ แต่คนกดไม่เห็นว่าวันไหน
  - ต้องส่ง `rules` ที่ `/api/om/follow?house=` ส่งมาอยู่แล้วเข้า `JobDetail`

### 2. ปุ่มผลการโทร

ปัญหา: grid 7 ช่องแต่มี 5 ปุ่ม — จอ 1440 ที่เปิดเมนูซ้าย "รับสาย · ตกลงนัด" ตกบรรทัดล้นปุ่ม · จอกว้างเหลือช่องว่างขวา

- 2 กลุ่ม หัวกลุ่มมีไอคอนโทรศัพท์ เขียว/แดง แบบ modal Follow-up ฝั่งขาย
  - **ติดต่อได้**: ตกลงนัด · ขอเลื่อน · ปฏิเสธ ไม่เอา
  - **ติดต่อไม่ได้**: ไม่รับสาย · เบอร์ผิด
  - การ์ดนัดหมายตอนชำระเงินแล้ว: ติดต่อได้ = ตกลงนัด · ขอเลื่อน / ติดต่อไม่ได้ = ไม่รับสาย (ชุดเดิม)
- ในฟอร์มใช้ป้ายสั้น (ตัด "รับสาย ·" เพราะหัวกลุ่มบอกแล้ว) — `CALL_OUTCOME` ที่ใช้ในประวัติ/Timeline/การ์ดรายการ**คงเดิม**
- ปุ่ม `flex-wrap` ความกว้างตามข้อความ ไม่ใช้ grid 7 ช่อง
- **ไม่เลือกผลไว้ก่อน** แบบฝั่งขาย (เดิมเลือก "ตกลงนัด" ไว้ให้) — ช่องวันนัด/นัดโทรใหม่โผล่หลังเลือกผล · ปุ่มบันทึกกดได้เมื่อเลือกผลแล้ว

### 3. แถบสรุปการโทรรอบนี้

ปัญหา: API ส่ง `calls · no_answer · last_call_at · last_outcome · last_by · next_call` มาแล้ว แต่การ์ดไม่แสดง
ต้องไล่ Activity Log เอง · ไม่รู้ว่าอีกกี่ครั้งจะตกแท็บติดต่อไม่ได้

- แถบเดียวบนสุดของฟอร์มโทร (อยู่ใน `callForm` ⇒ ขึ้นทั้งขั้น 01 และการ์ดนัดหมายตอนชำระเงินแล้ว)
  - `โทรรอบนี้ 2 ครั้ง · ไม่รับสาย 1/3 · ล่าสุด ไม่รับสาย 25 ก.ย. โดย <ชื่อ> · นัดโทรใหม่ 28 ก.ย. (เลยกำหนด)`
  - 1/3 = `no_answer` / `call.max_attempts` · ถึง max-1 ขึ้นส้ม "อีก 1 ครั้งจะย้ายไปแท็บติดต่อไม่ได้"
  - สีนัดโทรใหม่แบบหน้า lead: เลยกำหนด = แดง · วันนี้ = ส้ม · ยังไม่ถึง = เทา
  - ยังไม่เคยโทรรอบนี้ = "ยังไม่เคยโทรรอบนี้" บรรทัดเดียว
- ตัวเลขนับ "รอบนี้" (หลังล้างล่าสุด · `follow-sql.ts` ②) ชุดเดียวกับการ์ดในรายการ — ป้ายต้องมีคำว่า "รอบนี้" กันสับสนกับ Activity Log ที่เห็นทุกรอบ

### 4. มือถือ

ปัญหา: ราง STEPS กิน 80px การ์ดเหลือแคบ ชื่อขั้นตกบรรทัด · ปุ่ม Note ถูกตัดขอบขวาของแถบแท็บ

- ราง STEPS `hidden md:flex` แบบหน้า lead
- มือถือเรียงการ์ดทุกขั้นต่อกัน (แบบหน้า lead โหมดปกติ) · desktop ยังเปิดทีละการ์ดจากรางเหมือนเดิม
  - ทำด้วย class: การ์ดที่ไม่ได้เลือกบน desktop ใส่ `md:hidden` — ไม่ต้องมี hook วัดจอ
  - การ์ดที่ปิดแล้วบนมือถือพับไว้ (บรรทัดสรุป + ลูกศร) — state พับ/กางแยกรายการ์ด (เดิม `doneOpen` ตัวเดียว)
  - ข้าม / ยังไม่ถึง = หัวการ์ดเส้นประแบบเดิม · ขั้นที่ทำอยู่ขึ้นแทบบนสุดเองเพราะขั้นก่อนหน้าพับ ⇒ ไม่ต้อง auto-scroll
- แถบปุ่มล่างติดจอ `fixed md:hidden above-nav` ปุ่ม Note คลาสเดียวกับหน้า lead (O&M ไม่มี Follow-up ⇒ ปุ่มเดียวเต็มแถว)
  - ซ่อนปุ่ม Note ในแถบแท็บบนมือถือ · เผื่อ padding ล่างของเนื้อหาให้พ้นแถบ

## ทำจริง (29 ก.ย. 69)

- `OmSlotPicker.tsx` ใหม่ — ย้ายส่วนวัน+ช่วงเวลาออกจาก `OmRescheduler` จริง (Reschedule ใช้ตัวนี้แล้ว)
  - ผลโหลดผูกกับวันที่ขอ + ตัดผลของวันเก่าที่มาทีหลัง (เลื่อนแถบวันเร็ว ๆ) — แทนการ `setSlots(null)` ใน effect ที่ eslint ไม่ให้ผ่าน
  - วันนัดเดิมที่เลยมาแล้ว (ตอนเลื่อนนัด) ทุกช่วงกดไม่ได้ · แถบ "นัดเป็น / เลื่อนเป็น" บอกช่วงเต็ม เช่น 13:00–14:30
- `JobDetail.tsx`
  - ผลโทร 2 กลุ่ม ป้ายสั้น · ไม่เลือกไว้ก่อน (ปุ่มขึ้น "เลือกผลการโทร") · ช่องวัน/โน้ต/กล่องอธิบายโผล่หลังเลือกผล
  - บ้านสิทธิ์หมด + ตกลงนัด: ไม่โชว์ตัวเลือกช่วงเวลา (นัดตรงไม่ได้อยู่แล้ว) เหลือกล่องส้ม "ไปขั้น 02"
  - แถบสรุป: นัดโทรใหม่โชว์เฉพาะที่ยังค้าง (โทรตั้งแต่วันนัดไปแล้ว = ตามแล้ว ไม่ขึ้น "เลยกำหนด" ผิด)
    · คำเตือน "อีก 1 ครั้ง" เฉพาะขั้น 01 ที่กติกาตกแท็บใช้จริง (ไม่ใช่ใบซ่อมในประกัน · ไม่ใช่การ์ดนัดหมายหลังชำระเงิน)
  - มือถือ: การ์ด "ข้าม" เหลือหัวการ์ด (เนื้อใน "ทำไมข้าม" ดันขั้นถัดไปตกจอ) · desktop กดรางแล้วยังเห็นเนื้อในเหมือนเดิม
- หน้า `[house]` ส่ง `rules` จาก `/api/om/follow?house=` (มีครบ call.* booking.* reschedule.* อยู่แล้ว)
