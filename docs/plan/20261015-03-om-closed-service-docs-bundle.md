# PDF รวมใบบริการของแท็บปิดงาน (หน้าต่างรายชื่อบนภาพรวม O&M)

ที่มา: ผู้ใช้ถาม 15 ต.ค. 69 "กรณีปิดงานแล้ว ให้มีปุ่ม download ไฟล์ pdf รวมใบรายงานทั้งหมดตาม list ในเอกสารเดียว"
→ เคาะ "1. แท็บปิดงานอย่างเดียว 2. ตามแนะนำ (มีหน้าสรุปรายการ) 3. ตามแนะนำ (ย่อรูป)"

สถานะ: **เสร็จ 15 ต.ค. 69**

## ทำ

- ปุ่ม "PDF รวม" ในหัวหน้าต่างรายชื่อ ซ้ายปุ่ม Excel — เฉพาะหน้าต่าง "แท็บปิดงาน" (ภาพรวม O&M · แผน 20261015-02)
- route ใหม่ `GET /api/om/jobs/docs?ids=…` — เปิด Chromium ครั้งเดียว พิมพ์ใบบริการทีละใบตามลำดับในรายชื่อ แล้วต่อกันด้วย pdf-lib
  - หน้าแรก = หน้าสรุปรายการ: ลำดับ · เลขที่ใบบริการ · บ้าน · ลูกค้า · โครงการ · วันปิดงาน · ผลตรวจ · เริ่มหน้าที่
  - ใบที่ไม่มีใบตรวจรับงาน = ข้าม + เขียนไว้ท้ายหน้าสรุป + บอกบนหน้าจอ
  - รูปหน้างานย่อเฉพาะในไฟล์รวม (ด้านยาวไม่เกิน 1200px · JPEG) ด้วย sharp — ใบเดี่ยวยังฝังรูปเต็มเหมือนเดิม
  - ครั้งละไม่เกิน 50 ใบ (คำขอยาว — nginx prod มักตัดที่ 60 วินาที)
- ย้ายโค้ดสร้างใบบริการ (อ่านข้อมูล + HTML + ดักคำขอฟอนต์/รูป) ออกจาก `/api/om/jobs/[id]/doc` ไป `src/lib/om/service-doc-pdf.ts`
  ใบเดี่ยวกับไฟล์รวมใช้ตัวเดียวกัน ⇒ หน้าตาตรงกันเสมอ

## ไฟล์

- ใหม่ `src/lib/om/service-doc-pdf.ts` · `src/app/api/om/jobs/docs/route.ts`
- `src/app/api/om/jobs/[id]/doc/route.ts` — เรียกตัวกลาง (ผลลัพธ์เหมือนเดิม)
- `src/components/om/OmDashBucketModal.tsx` — ปุ่ม PDF รวม
- `src/lib/om/service-doc.ts` — export ข้อมูลบริษัท (หน้าสรุปใช้หัวเดียวกัน)

- ใบเดี่ยวหลังย้ายโค้ด: ขนาดไฟล์เท่าเดิมทุกไบต์ (#134 120,974 · #148 121,750) · 2 หน้าเท่าเดิม
- แท็บปิดงาน 19 ใบ: 36 หน้า = ปก 1 + ใบบริการรวม 35 (เท่าผลรวมใบเดี่ยว) · 2.6 MB · เลขหน้าในหน้าสรุปพาไปใบถูกครบ 19 แถว
