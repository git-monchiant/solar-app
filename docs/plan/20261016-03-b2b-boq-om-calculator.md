## สมมติฐาน (หลักการ) — ต้องถามทีมยืนยันภายหลัง

1. ตัวเลขในสูตรค่าแรงผู้รับเหมา `((ระยะทาง×10)+(A×1500)+(B×800))×วัน` — **A = หัวหน้าช่าง 1,500 บาท/วัน · B = ช่าง 800 บาท/วัน**
   (ไฟล์พิมพ์ฝังในสูตรและเปลี่ยนทุกไฟล์: 1/5 · 2/8 · 1/4) · ระยะทาง×10 = ค่ารถผู้รับเหมาวันละเที่ยว
2. **ค่าที่พัก/เบี้ยเลี้ยงคิดเฉพาะโครงการต่างพื้นที่** — ทุกไฟล์พิมพ์จำนวน 0 (โครงการในพื้นที่) · ป้ายในไฟล์บอกวิธีนับ
   "ห้อง×วัน×ครั้ง×ปี" / "คน×วัน×ครั้ง×ปี" และหัวบรรทัดที่พักเขียน "ครั้งละ ⌈คน/2⌉ ห้อง"
3. **"ในพื้นที่" = ไป-กลับได้ในวันเดียว ไม่ต้องค้างคืน** — สูตรเบี้ยเลี้ยงเดิม `IF(F271=T272,300,0)` อ้างช่องว่างทั้งคู่ (ได้ 300 เสมอ) เลยใช้เป็นสวิตช์ไม่ได้
4. ระยะทางไม่มีค่าเริ่มต้น (ต่างกันทุกโครงการ) — หน้าจอเตือนเมื่อยังเป็น 0
