# จัดกลุ่ม "การแก้ไข" ใน Timeline ตามประเภทและเหตุการณ์ที่เกี่ยวข้อง

วันที่: 2026-08-20
สถานะ: done

แทนที่แนวทางของ [20260820-07](20260820-07-timeline-milestone-sla-focus.md) ที่ถูกยกเลิกไป
รอบนั้นซ่อนแถวทิ้งเฉย ๆ รอบนี้ยุบเป็น **กลุ่มที่กดขยายได้** และ **แยกตามประเภท**
โดยผูกกลุ่มไว้กับเหตุการณ์ที่มันแก้

## กติกา

| ประเภทแถว | ผล |
| --- | --- |
| แถว SLA | แสดงเสมอ |
| Milestone จาก column ของ lead | แสดงเสมอ |
| ผลลัพธ์ทางธุรกิจ: ยืนยันชำระเงิน, ส่งใบเสนอราคา, ลูกค้ายืนยัน, ใบรับประกัน, ขอขนานไฟ | แสดงเสมอ |
| **นัดหมายล่าสุดของขั้นนั้น** | แสดงเสมอ |
| นัดหมายที่ถูกยกเลิก/แทนที่ไปแล้ว | กลุ่ม **ประวัติการแก้ไขนัด** — ซ้อนอยู่ใต้แถวนัดที่ยังมีผล |
| `status_change` รวม rollback | กลุ่ม **การเปลี่ยนสถานะ** — ท้ายขั้น |
| note และกิจกรรมติดต่อ (call, visit, line, follow_up) | กลุ่ม **บันทึกการติดต่อ** — ท้ายขั้น |

"นัดหมายล่าสุด" คือ activity ประเภท `appointment_*` ที่ใหม่ที่สุดของขั้นนั้นและไม่ใช่การยกเลิก
คือนัดที่ยังมีผลอยู่จริง ส่วนนัดก่อนหน้าถือเป็นประวัติการแก้ไขของนัดนั้น

ถ้าขั้นไหนไม่มีนัดที่ยังมีผลเหลืออยู่ (เช่นยกเลิกแล้วไม่ได้นัดใหม่) ประวัติการแก้ไขนัด
จะกลายเป็นกลุ่มระดับขั้นแทน เพื่อไม่ให้ไม่มีที่แขวน

        นัดติดตั้ง 9 ก.ค. 2569 · 3 ก.ค. 21:01

        นัดติดตั้ง 9 ก.ค. 2569 · 6 ก.ค. 10:36

  ▸ การเปลี่ยนสถานะ (2)

จาก 9 แถว เหลือ 4 แถว + 2 กลุ่ม และแต่ละกลุ่มบอกชัดว่าเป็นเรื่องอะไร

## จุดที่ต้องแก้เพิ่มเพื่อไม่ให้ข้อมูลหาย

แถว milestone จาก column ของ lead ถูกกันไม่ให้ซ้ำด้วยการเช็คว่ามีแถว activity
ที่พูดเรื่องเดียวกันอยู่แล้วหรือยัง ถ้าปล่อยไว้ แถวที่เข้ากลุ่มจะยังกัน milestone ไว้
ทำให้ตอนพับกลุ่มแล้วขั้นนั้นไม่เหลืออะไรเลย

แก้โดยให้การเช็คทั้ง 10 จุดนับเฉพาะแถวที่แสดงจริง (`!row.detail`) — เช่นถ้า
"สำรวจเสร็จและเข้าสู่ขั้นใบเสนอราคา" เข้ากลุ่มการเปลี่ยนสถานะไป ขั้น Survey
จะได้แถว "เข้าสำรวจหน้างานจริง" จาก `survey_actual_date` มาแทน

## รายละเอียดอื่น

- แต่ละกลุ่มจำสถานะเปิด/ปิดแยกกันด้วย key `<stage>:<group>`
- ตัวเลข x/y ที่หัวขั้นนับเฉพาะแถวที่แสดงตามปกติ จึงไม่กระโดดตอนกดขยาย
- กลุ่มเหล่านี้เป็นทางเดียวที่ผู้ใช้มือถือเข้าถึงรายละเอียดได้ เพราะ Activity Log
  เป็น `hidden md:flex` และปุ่ม tab ถูกถอดออกไปแล้ว
