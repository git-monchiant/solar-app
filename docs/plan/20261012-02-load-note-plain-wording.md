# รายงานสำรวจ §3: ข้อความใต้ตาราง Load Assumption ให้อ่านเข้าใจง่าย

ต่อจาก: [20261012-01-water-heater-household-minutes.md](20261012-01-water-heater-household-minutes.md)

## ที่มา

ผู้ใช้ชี้บรรทัดใต้ตาราง §3 (ลีด #924) ว่าอ่านยาก:

> สัดส่วนใช้ไฟกลางคืน ≈ 49% · คำนวณจาก 7/9 รายการ · กำลังไฟเป็นค่ามาตรฐานโดยประมาณ (แอร์คิดภาระเฉลี่ย กลางวัน 70% · กลางคืน 55% ของกำลังเต็ม)

- ผลลัพธ์กับหมายเหตุปนอยู่ในบรรทัดเดียว
- "7/9 รายการ" ต้องนับตารางเองว่าขาดอะไร
- "ภาระเฉลี่ย" เป็นศัพท์ช่าง

## การเปลี่ยนแปลง

แยกเป็น 2 บรรทัด:

1. **ผลลัพธ์** (ตัวปกติ) — "สัดส่วนใช้ไฟกลางคืน ≈ **49%** ของการใช้รวม" ใช้คำเดียวกับกล่อง Battery ด้านล่าง
   ("> 40-50% ของการใช้รวม") · ตอบครบ → ต่อด้วย "ยอดประมาณการเท่ากับ ≈ **X%** ของไฟที่ใช้จริงตามบิล (… บาท/เดือน)"
2. **หมายเหตุ** (ตัวเล็กสีเทา):
   - "ยอดรวมยังไม่นับ เครื่องทำน้ำอุ่น, ปั๊มน้ำ (ข้อมูลยังไม่ครบ)" — บอกชื่อแทน 7/9 · แถว "ไม่ทราบ" แยกเป็น "(ลูกค้าไม่ทราบ)"
     · แอร์กลางวัน/กลางคืนรวมเป็นชื่อเดียว · ครบทุกรายการ → ไม่พิมพ์ส่วนนี้
   - "กำลังไฟใช้ค่ามาตรฐานของอุปกรณ์แต่ละประเภท ไม่ได้วัดจากเครื่องจริง"
   - (มีแอร์) "แอร์คิดที่ 70% (กลางวัน) และ 55% (กลางคืน) ของกำลังเต็ม เพราะแอร์ไม่ได้ทำงานเต็มกำลังตลอดเวลาที่เปิด"

## รอบ 2 — ตาราง "สรุปการคำนวณ" (12 ต.ค.)

ผู้ใช้ (ใบเสนอราคา #67 / ลีด #924): "≈ 16% ของไฟที่ใช้จริงตามบิล" ยังไม่รู้ว่ามาจากไหน → ขอสรุปการคำนวณแบบเข้าใจง่าย

แทนบรรทัดแรกด้วยตาราง `kv qsum` (ตัวเดียวกับตารางหัว §3) หัวซ้ายสีกรม "สรุปการคำนวณ":

| แถว | ตัวอย่าง #924 |
| --- | --- |
| ใช้ไฟรวมต่อวัน | กลางวัน 5.4 + กลางคืน 4.4 = **9.8 kWh/วัน** |
| สัดส่วนใช้ไฟกลางคืน | กลางคืน 4.4 ÷ รวม 9.8 = **45%** ของการใช้รวม |
| ประมาณการต่อเดือน * | 9.8 kWh × 30 วัน = **294 kWh/เดือน** |
| ไฟที่ใช้จริงตามบิล * | ค่าไฟ 9,000 บาท ÷ 5 บาท/หน่วย (ค่าไฟเฉลี่ย) ≈ **1,800 kWh/เดือน** |
| เทียบกับบิล * | 294 ÷ 1,800 ≈ **16%** — ความหมายตามช่วง |

\* เฉพาะเมื่อตอบครบ (เกณฑ์เดิม) · ค่าไฟต่อหน่วยใช้ของใบเสนอราคาถ้ามี ไม่งั้น 5 บาท

ความหมาย — ผู้ใช้ขอบรรทัดเดียวและเข้าใจง่าย เลือกจาก 4 ชุดเป็นชุด "บอกว่าบิลมีอะไรอีก" (เล่าจากมุมบิล):
< 70% "บิลจริงยังมีการใช้ไฟจากเครื่องใช้ไฟฟ้าอื่นที่ไม่ได้อยู่ในตาราง" ·
70–130% "ตัวเลขในตารางใกล้เคียงกับบิลจริง" ·
> 130% "ตัวเลขในตารางสูงกว่าบิลจริง ชั่วโมงใช้งานจริงอาจน้อยกว่าที่ประมาณ"
— ตรวจจาก PDF จริง `/api/quotation-pdf/67` หน้า 6: แถว "เทียบกับบิล" อยู่บรรทัดเดียว · เคส > 130% ก็บรรทัดเดียว

## รอบ 3 — ถอดหมายเหตุแอร์ (12 ต.ค.)
