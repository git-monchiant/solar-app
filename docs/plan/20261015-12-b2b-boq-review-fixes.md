# ทบทวนงาน BOQ B2B + แก้ข้อที่ต้องแก้ก่อนใช้งานจริง

สถานะ: **in-progress** — กลุ่ม 🔴 (5 ข้อ) แก้แล้ว 15 ต.ค. · กลุ่ม 🟡 / ⚪ ค้าง (backlog)

## ที่มา

ผู้ใช้ขอ "ทบทวนงาน boq" (15 ต.ค.) หลังผูก BOQ กับโครงการ · ใบเสนอราคา · จัดซื้อ · แยกการ์ด
รีวิวอ่านโค้ด 2 ส่วนคู่ขนาน (server/คำนวณ · หน้าจอ) + รันชุดทดสอบการคำนวณ — ผู้ใช้สั่ง "แก้เลย" กลุ่ม 🔴

**ส่วนที่ดีอยู่แล้ว**: ตัวเลขตรงกันทุกจุด (calcBoq · ยอดหัวใบ · Excel · ยอดตั้งต้นใบเสนอราคา · ชุดทดสอบผ่าน) · บันทึก/ออก Rev ล็อกแถวกันชน ·
Purchase เข้าหน้า BOQ/ใบเสนอราคา/โครงการไม่ได้ · ผู้ตรวจสอบอ่านอย่างเดียว · tsc/eslint ผ่าน

## 🔴 แก้แล้ว (15 ต.ค.)

| # | ปัญหา | แก้ |
|---|---|---|
| 1 | บรรทัด "รอราคา" ไม่รับราคาที่ Purchase ใส่แล้ว → ปุ่มบันทึกกดไม่ได้ ยอดรอราคาค้าง **ใบเสนอราคาส่งอนุมัติไม่ได้** | Purchase บันทึกราคา (`/api/b2b/materials/prices`) → บรรทัดรอราคาของ BOQ ที่ยังแก้ได้รับราคาเอง + คำนวณยอดหัวใบใหม่ + timeline "ราคาเข้า BOQ" (เฉพาะ Rev ล่าสุด · ใบเสนอราคายังไม่ส่ง · โครงการยังไม่ผ่านราคายืนยัน · หน่วยคิดราคา/วัตต์ตรง Master) · หน้าทำ BOQ ที่เปิดค้างไว้มีปุ่ม "Purchase ใส่ราคาแล้ว · ใช้ราคานี้" |
| 2 | ลบช่อง Margin → หน้าจอคิด 0% แต่บันทึกเป็น 15% | บันทึกต้องระบุ Margin (ค่าเริ่มต้น 15% เฉพาะตอนสร้างใบ) · ตรวจหลังปัด 3 ตำแหน่ง (99.9996 → 100 ไม่ผ่าน) |
| 3 | ส่งอนุมัติใบเสนอราคาที่อ้าง BOQ Rev เก่าได้ | ส่งอนุมัติต้องอ้าง Rev ล่าสุด (บอกให้เลือก Rev ล่าสุดในใบ) · หน้าใบเตือน · ล็อกแถว BOQ ตอนส่ง (กันชนกับการบันทึก BOQ — ข้อ 🟡 8 เดิม) |
| 4 | หน้าจัดซื้อส่งบรรทัด "% ของยอดขาย" (ประกันภัย) → Purchase หารกลับได้ราคาขาย/margin | ไม่ส่งบรรทัด pct_sale · งบหมวด/งบรวม = ผลบวกบรรทัดที่แสดง · หน้าจัดซื้อบอกว่าไม่รวมรายการ % ยอดขาย |
| 5 | หน้า BOQ ไม่ดูขั้นโครงการ — ได้งาน/ปิดแล้วยังแก้ตัวเลือกอื่น/ออก Rev ได้ | `boqStageLocked` (ผ่านขั้นราคายืนยัน = แก้/ออก Rev ไม่ได้) ใช้ทั้ง API บันทึก · API ออก Rev · หน้าทำ BOQ (แถบเตือน · ซ่อนปุ่ม) · ราคาจาก Purchase ไม่เข้า BOQ ของโครงการที่ได้งานแล้ว |

## 🟡 ค้าง — ควรแก้รอบถัดไป

- 6 ออกจากหน้าภายในแอป (เปลี่ยน Rev · กลับ · เมนู) ไม่เตือนงานที่ยังไม่บันทึก — หน้าทำ BOQ + หน้าวัสดุและราคา (Purchase)
- 7 ถูกล็อกระหว่างแก้ (มีคนส่งใบเสนอราคาที่อ้าง Rev นี้) → บันทึก 409 · ออก Rev ไม่ได้เพราะยังมีงานค้าง → ต้อง reload งานหาย
- 9 แก้หน่วยคิดราคา/วัตต์ของวัสดุที่มีราคาแล้ว ความหมายราคาเปลี่ยน (ควรรีเซ็ตเป็นรอราคา + ลงประวัติ) — การเติมราคาเองข้อ 1 ตรวจหน่วยตรงกันแล้ว
- (8 ชนกันตอนบันทึก BOQ กับส่งอนุมัติ — แก้ไปพร้อมข้อ 3 แล้ว)

## ⚪ ข้อย่อย

- บัญชีเห็นต้นทุน/margin ในตาราง BOQ หน้าโครงการ + ลิงก์ BOQ เปิดแล้วไม่มีสิทธิ์
- ข้อความ "บรรทัดที่ N" ไม่ตรงเลขบนจอ (บรรทัดใส่ราคาเองป้ายเปลี่ยนเป็น "ยังไม่ใส่ราคา" แล้ว)
- แถบปุ่มหน้าวัสดุบนมือถือ `bottom-20` ลอยเหนือแถบล่าง · กดซ้ำ/พิมพ์ระหว่างบันทึก
- ตรวจค่า: เลี่ยงเลือกวัสดุปิดใช้งานผ่าน id บรรทัดเดิม · ไม่จำกัดจำนวน/ราคาสูงสุด (DECIMAL ล้น = 500)
- เปลี่ยนชื่อตัวเลือกแก้ Rev เก่าที่ล็อกตามไปด้วย · kWp นับแผงในหมวดส่วนเสริมแบบทางเลือก · เลขที่ BOQ เกิน 999/เดือน
- ของค้างก่อนมีโครงการ: ตอนบันทึกยังตรวจชื่อโครงการ/ลูกค้า/พิกัดจากหน้าจอ (แต่ใช้ค่าจากโครงการ) · `b2b_boqs.project_id` ยังว่างได้
