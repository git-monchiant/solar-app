## 2. สิ่งที่ยกแนวคิดจาก O&M เดิม (ไม่ยกโค้ด)

| O&M เดิม (บ้าน) | O&M B2B (โรงงาน 1 ไซต์) |
|---|---|
| สิทธิ์ล้างแผง (ledger grant/redeem) ผูกบ้าน · ครั้งที่ N · คงเหลือ | **สัญญา O&M ต่อโครงการ** ครั้งรวม = ปี × ครั้ง/ปี · ครั้งที่ N / M |
| ไม่มีคิวล่วงหน้า — แท็บติดตามคำนวณบ้านที่ถึงรอบ แล้วโทรนัด | **ตารางเข้างานสร้างล่วงหน้าทั้งสัญญา** (ไซต์ใหญ่ วางแผนกับฝ่ายอาคารของลูกค้า) |
| 1 นัด = 1 บ้าน = ล้างแผง ใบตรวจขนาดบ้าน | 1 นัด = 1 ไซต์ อาจหลายวัน · ใบตรวจระดับอินเวอร์เตอร์/สตริง |
| ใบบริการ PDF · ลายเซ็นลูกค้า/ช่าง/Q.C. | รายงานบริการ PDF ผังเดียวกัน + ค่าวัดรายอินเวอร์เตอร์ |
| จ่ายก่อนนัด (งานนอกสิทธิ์) · LINE/LIFF ลูกค้าจองเอง | สัญญารวมในราคาโครงการแล้ว · ติดต่อผ่านผู้ประสานงานของลูกค้า (ไม่ทำ LINE) |
| ทีมช่าง + สล็อตเวลา บนปฏิทินกลาง | **Solar B2B ทำเอง** (role `b2b` เดิม) · **ปฏิทินแยก** ไม่ปนคิวช่าง O&M บ้าน (เคาะ 15 ต.ค.) |

ส่วนที่ผูกบ้าน/B2C ใช้ไม่ได้: `om_houses` · REM sync · ลีด · "ลูกค้าไม่อยู่บ้าน" · แพ็กเกจตาม kW · LINE/LIFF

## 3. ข้อเสนอ — flow

```
ปิดโครงการ 3950 ─▶ สร้างสัญญา O&M เอง (เริ่มวันส่งมอบ · สิ้นสุด +om_years ปี)
                   + ตารางเข้างาน om_years × om_visits_per_year ครั้ง กระจายเท่ากัน
                     (2 ปี ปีละ 2 = เดือนที่ 6 · 12 · 18 · 24 นับจากวันส่งมอบ)
                   + รายการอุปกรณ์จาก BOQ ที่ได้งาน (แผง · อินเวอร์เตอร์ — เติม S/N ได้)

ครั้งที่ N:  ถึงรอบ (เดือนนี้/เดือนหน้า) ─▶ นัดวัน + ทีม ─▶ เข้างาน (ใบตรวจ · รูป · ค่าวัด)
             ─▶ ลูกค้าเซ็นรับ ─▶ ปิดงาน + รายงาน PDF  (ครั้งที่ N / M)

แจ้งซ่อม/เคลม (เมื่อไรก็ได้): เปิดเคส ─▶ ตรวจ ─▶ ในประกันติดตั้ง = ฟรี · ประกันผู้ผลิต = เคลม supplier
                             · นอกประกัน = เสนอราคา ─▶ ซ่อม ─▶ ปิดเคส

ใกล้หมดสัญญา (60 วัน) ─▶ เตือนเสนอต่อสัญญา (ภายหลัง)
```
