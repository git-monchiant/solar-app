# Load Assumption: เตือนบนการ์ดที่กรอกไม่ครบ (เช่น ใส่ชั่วโมงแต่ไม่ใส่จำนวน)

วันที่: 12 ต.ค. 2569 · branch: `v3-ui-consistency` (ทำในเครื่อง)
ต่อจาก: [20261012-02-load-note-plain-wording.md](20261012-02-load-note-plain-wording.md)

## ที่มา

ผู้ใช้ถาม (ลีด #924): ปั๊มน้ำใส่ชั่วโมงได้ทั้งที่ยังไม่ใส่จำนวนเครื่อง และระบบไม่เตือน

- `computeLoad` ถือว่าแถวนั้น "partial" แล้วตัดออกจากยอดรวมแบบเงียบๆ
- ที่เดียวที่บอกคือ "คำนวณได้ 7/9 รายการ" สีเทาท้ายแถบสรุป
- ประตูส่งใบเสนอราคาเข้าอนุมัติจะบล็อกทีหลัง (`missingLoadAnswers`) แต่ตอนกรอกไม่รู้ตัว
- เครื่องทำน้ำอุ่นในภาพก็ไม่ถูกนับเหมือนกัน (กลางวันยังเป็น "–")

## การตัดสินใจ

- **D1** เตือน ไม่ล็อก — ยังกรอกชั่วโมงก่อนจำนวนได้ (เซลส์ถามลำดับไหนก็ได้) ตามแนวเดิมของตัวกรอกนี้ที่เตือนอย่างเดียว
- **D2** เตือนเฉพาะการ์ดที่ **เริ่มกรอกแล้ว** แต่ยังไม่ครบ — การ์ดที่ยังไม่แตะไม่ขึ้นสีเหลือง (ไม่งั้นเปิดมาเหลืองทั้งหน้า)
- **D3** บนการ์ด: กรอบสีเหลือง + ป้ายช่องที่ขาดเป็นสีส้ม + "ยังไม่นับในยอดรวม — ยังไม่ได้ใส่ **จำนวน · กลางคืน**"
  และถ้าขาดช่องชั่วโมงบอก "(ช่วงที่ไม่ได้ใช้ กด − ให้เป็น 0)"
- **D4** แถบสรุป: "ยังไม่นับ: เครื่องทำน้ำอุ่น, ปั๊มน้ำ (กรอกไม่ครบ)"
